# 网页屏蔽器（Edge / Chrome 扩展）v1.4.6

点一下网页上任何区域 → 记住「这个站点 + 这个区域」→ 以后每次打开都自动屏蔽它，并**收回父级为它预留的空白**，其余内容自动补位。支持多条规则、整站或单页生效、批量屏蔽同类区域、快捷键暂停、隐藏或真删节点、规则导入导出。纯本地存储，不联网、不上传任何数据。

## 安装

1. 把 `web-blocker` 文件夹放到固定位置，例如 `D:\edge-extensions\web-blocker`。
2. Edge 打开 `edge://extensions` → 左下角开「开发人员模式」。
3. 点「加载解扩展」选中该文件夹。
4. 因为要能在任意网站生效，安装时 Edge 会提示「**读取和更改您在所有网站上的所有数据**」——这是通用屏蔽器的必然要求，不接受就只会在个别站点工作。
5. 想常驻看到那个捂眼小幽灵：点工具栏右侧的拼图图标 → 找到「网页屏蔽器」→ 点**固定**。

> **升级注意**：不要删除、改名或移动已加载的文件夹——浏览器按安装时登记的路径读文件，路径失效后点图标会报 `ERR_FILE_NOT_FOUND`、面板打不开。正确做法：把新版本文件**覆盖**进原文件夹，然后在 `edge://extensions` 点「重新加载 ↻」。
> **已经误删/移动了**：优先把（新版）文件放回**原来登记的那个路径**再点「重新加载」——扩展 ID 不变，屏蔽规则和暂停状态全部保留。只有在原路径无法恢复时才删除扩展重新加载，删除会清空浏览器存储里的规则。
6. 改过文件后记得在扩展卡片上点「**重新加载 ↻**」，再回页面刷新。

## 屏蔽一个区域

1. 打开目标网页 → 点工具栏里的扩展图标 → 点「**在此页面上点选屏蔽**」。
2. **移动鼠标 = 虚线预览**，**单击 = 选中成实线**。选中后鼠标再怎么移动、掠过别的元素都只改预览框，不会动你的选区，可以放心把鼠标移到下面的确认条上。
3. **多选**：按住 **Ctrl（Mac 为 Cmd）单击**可连续追加区域，每个已选区域都有一个实线框；对已选区域再按 Ctrl+单击则把它**移除**。散落在页面各处的几个广告位可以一次屏蔽，确认后合并成**一条规则**（选择器自动去重）。
4. 微调选区（可选，选中后随时可用）：
   - `↑` 选父级容器、`↓` 进入第一个子元素——从一张卡片放大到整个卡片列表，或反过来，不用跟嵌套结构较劲；**优先作用于鼠标悬停的那块已选区域**，没悬停已选块时作用于最后点的那块。
   - **Alt + 点击**：等价于 `↑`，把鼠标所在（或最后点的）那块原地升一层。
   - **普通单击**：把整个选区替换成新点的那块（选错了就重新点）。
   - 多选的完整玩法见下面「使用示例」。
5. 确认条上两个选项：
   - **同时屏蔽同类区域（勾选后约屏蔽 N 个）**：对每个已选区域，把同一父级下长得一样的兄弟一起屏蔽；找不到可安全批量匹配的元素时这项会自动禁用。
   - **整站生效**：默认勾选，该网站所有页面都屏蔽；取消勾选则只在当前这个网址（origin + path）生效。
6. 点「**确认屏蔽**」或直接按 **Enter**，立即生效不用刷新；按 `Esc` 取消。

弹窗会在你点页面时自动关闭，这是正常的——规则已经由页面里的确认条存好了，重新打开弹窗就能看到。

## 使用示例：一次屏蔽知乎首页的三个区域

假设目标是：顶部的活动横幅、左侧图标栏、右下角的推荐卡片列，一次全干掉，且各自挤占的空白都收回。

点扩展图标 →「在此页面上点选屏蔽」进入点选模式后，按下面顺序操作（表格里的选择器是示意，以实际页面为准）：

| 步骤 | 你做什么 | 页面上的反馈 |
| --- | --- | --- |
| 1 | 鼠标移到顶部横幅 | 横幅套上红色**虚线框**（只是预览），确认条显示引导文案，「确认屏蔽」置灰 |
| 2 | **单击**横幅 | 虚线变**实线**，摘要行显示「已选 1 个区域：div[data-za-detail-view-path]…」 |
| 3 | **按住 Ctrl 单击**左侧图标栏 | 左栏也套上实线框，摘要变「已选 2 个区域：…、.AppAside」 |
| 4 | **按住 Ctrl 单击**右下推荐列 | 第三个实线框出现，摘要「已选 3 个区域：… 等」 |
| 5 | 某块点错了 | 对它再 **Ctrl+单击**：它的实线框消失、从选区移除，其他块不受影响；想推倒重来，**普通单击**任意一块即可整体替换 |
| 6 | 左栏想连它的容器一起屏蔽 | 鼠标悬停在那一块上按 **↑**（或 **Alt+点击**）——只把这一块升级成父级容器，其他选区不动；升过头按 **↓** 降回来 |
| 7 | 勾选「同时屏蔽同类」「收回留白」 | 前者显示「勾选后约屏蔽 N 个」（各选区的同类合计）；后者把各块父级预留的空白一并收回 |
| 8 | 按 **Enter** 或点「确认屏蔽」 | 三块同时消失、内容自动补位；弹窗里多出**一条**规则，标签为「3 个区域 · 首个选择器」 |

示例里藏着两条容易踩的点，单独说明：

- **普通单击会整体替换选区**（第 2 步的语义），所以追加一律用 Ctrl+单击；选区乱了就普通单击任意一块推倒重来。
- **`↑`/`↓`/Alt+点击 优先作用于鼠标悬停的那块已选区域**（悬停处不是已选区域时，作用于最后点的那块），所以多选之后也能逐块微调，不用按添加顺序来。

之后打开知乎任何页面：三个区域都被隐藏、父级留白被收回。临时想全看按 `Alt+Shift+B`；想撤掉这条规则，弹窗里删除即可。

## 收回留白（自动补位）

先澄清一个常见误解：**「隐藏」(`display:none`) 本身就会让后面的内容收上来**，和真删节点在布局上没区别。你看到的那块空白通常不是被屏蔽元素占着的，而是**父级为它预留的**——所以本扩展在屏蔽之后会多做一步「收回留白」，默认开启：

- 父级的 `padding-left` / `margin-left` / `padding-top` / `margin-top`（固定侧栏、顶栏最常见的补偿写法）
- 父级是 grid 且写了**固定轨道**（`grid-template-columns: 220px 1fr` 里那一列不会因为元素消失而塌掉，这里把它改成 `0px`）
- 父级自己是 `position: fixed / absolute` 且带 `left` / `top` 偏移

判定很保守，避免误伤正常留白：预留值必须 **≥ max(32px, 被屏蔽块对应边的 65%)** 才动手，并且**只往上找到的第一层就收工**，不会层层清零。所有改动都备份了原值，关掉规则、暂停站点或删除规则都会逐条还原。

补位把版面弄乱时（例如那块空白其实是设计上的间距），取消勾选即可：点选时确认条里的「**收回留白**」，或弹窗规则行里的同名复选框。

已知局限：改写 grid 轨道时，剩余轨道的 `1fr` 会被固化成当前算出的像素值，窗口大幅缩放后那一列不会跟着重新拉伸。这种情况改用「真删除节点」或关掉补位。

## 快捷键暂停

| 快捷键 | 作用 | 会不会记住 |
| --- | --- | --- |
| `Alt+Shift+B` | 暂停 / 恢复**当前这个页面** | 不记住，刷新或重新打开页面就恢复屏蔽 |
| `Alt+Shift+S` | 暂停 / 恢复**整个站点** | 记住，换到该站任何页面都保持暂停 |

按完之后页面左下角会弹一条两秒的提示（`⏸ 已暂停本页屏蔽 —— 再按 Alt+Shift+B 恢复`），扩展图标上同时会出现 **⏸ 角标**，一眼能看出当前页面处于暂停状态。之所以分两级：临时看一眼被屏蔽的内容用 B（不打扰你之后浏览），这段时间想彻底关掉该站用 S。

改键或发现按键没生效：地址栏进 `edge://extensions/shortcuts`（Chrome 是 `chrome://extensions/shortcuts`），在那里能看到实际绑定并修改——`Alt+Shift+B` 之类可能被 Edge 自身或其他扩展占用。弹窗里也有同样的「暂停本页 / 暂停本站」按钮，效果完全一致。

被暂停的站点会列在弹窗的「已暂停站点」里，点站点名后面的 ✕ 就能恢复，不用先跑到那个页面上去。

## 管理规则

弹窗里列出当前站点的规则（可切到「显示全部规则」），每条可以：

- **启用 / 停用**：停用后页面立刻还原，规则本身保留。
- **隐藏 / 真删除节点**：默认「隐藏」（`display:none`，最安全，SPA 重渲染后仍能重新命中）。「真删除」会把节点从 DOM 里摘掉，某些 React/Vue 站点可能因此报错或把它重新渲染出来，遇到异常就切回隐藏。
- **删除**：连同规则一起清掉，被真删的节点会插回原来的位置。
- **命中 N 处 / 当前页面未命中**：未命中通常说明网站改版了，删掉规则重新点一次即可。

底部「导入 / 导出规则」可以把规则备份成 JSON 或换机器导入。

## 选择器是怎么生成的

按稳定性从高到低依次尝试，只有前一级不能唯一命中才降级：

1. `#id`
2. `tag[data-xxx="值"]`（知乎、B 站等大量使用 `data-test-id`、`data-za-*`）
3. 可读 class（`.AppAside`、`div.Card`；含 `: /` 等特殊字符的 class 如 Tailwind 的 `sm:w-1/2` 会经 `CSS.escape` 转义后正常使用）
4. 哈希 class 组合（`div.css-1a2b3c.css-4d5e6f`）——比结构路径抗重排
5. 结构路径 `body > div:nth-child(2) > section:nth-child(1)`——最后兜底，改版最容易失效

批量屏蔽时会额外校验：候选选择器必须命中 ≥2 个元素、且全部落在「同类」集合内，宁可放弃批量选项也不多杀。同时有护栏：选择器命中 `body` / `html` 时直接跳过，避免把整页干掉。

## 性能

脚本会注入到所有 http/https 页面，但**没有匹配规则时不挂 MutationObserver、不做任何 DOM 扫描**，只读一次本地存储；有规则时才挂观察者应对 SPA 局部渲染。

## 排障

- **点选后没反应**：看浏览器地址栏是不是 `file://`、`edge://` 或扩展商店页，这些页面不允许注入。
- **规则在但没屏蔽**：弹窗点「重新应用」；仍不行就是选择器失效（网站改版），删掉重点。
- **屏蔽后页面坏了**：把该规则从「真删除节点」改回「隐藏」，或直接删规则。
- **屏蔽后还留着一块空白**：那是父级预留的，不是元素本身占的。先确认该规则的「收回留白」是开着的；若仍没收，用 `↑` 把目标换成父级容器再点一次（直接屏蔽容器比让扩展反推留白更可靠）。
- **快捷键没反应**：去 `edge://extensions/shortcuts` 看绑定是否被吃掉或没生效；先在弹窗里点「暂停本页」验证功能本身正常，再改键。
- **想临时全关**：弹窗顶部「全局启用」开关，一键还原所有站点。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单，注入 http/https，声明两个快捷键，权限只有 `storage` + 主机访问 |
| `background.js` | 接收快捷键命令转发给页面、维护图标上的 ⏸ 角标、规则写入串行队列（防多标签页并发覆盖） |
| `content.js` | 规则匹配与应用、点选拾取器、选择器生成、暂停状态、可逆还原 |
| `popup.html` `popup.js` | 点选入口、暂停按钮、规则列表管理、导入导出 |
| `icons/` | 捂眼小幽灵图标 16 / 32 / 48 / 128（透明底 PNG），另附 512 源图可做商店素材 |
| `tools/gen_icons.py` | 图标生成脚本（Pillow，512 画布绘制 + Lanczos 缩放），改配色后重跑即可 |
| `tools/package.py` | 一键打包：语法检查 → 集成测试 → manifest 与图标校验 → `dist/web-blocker-v<版本>.zip` |
| `一键打包.bat` | 上一个脚本的双击即用版（Windows） |
| `tests/blocker-harness.mjs` | 假 DOM 集成测试：用 Node 直接执行 `content.js`，覆盖识别 / 补位 / 多选 / 暂停等全部行为 |
| `CHANGELOG.md` | 按 Keep a Changelog 格式维护的版本历史 |

## 项目结构与开发

```text
web-blocker/
├── manifest.json          # 入口声明：注入范围、快捷键、图标
├── background.js          # Service Worker：快捷键分发 + 角标 + 规则写入串行队列
├── content.js             # 核心逻辑（全部在这一个文件）
├── popup.html / popup.js  # 弹窗 UI
├── icons/                 # 各尺寸图标
├── tools/gen_icons.py     # 图标生成脚本（需 Pillow）
├── tools/package.py       # 一键打包：检查 → 测试 → 出 dist zip
├── 一键打包.bat           # 双击即用版打包（内部调 tools/package.py）
├── tests/blocker-harness.mjs
├── dist/                  # 打包输出（git 忽略）
├── README.md / CHANGELOG.md / .gitignore
```

- **无构建步骤、零依赖**：改完 `content.js` 保存 → `edge://extensions` 点「重新加载 ↻」→ 刷新页面即可验证。
- **本地自检**：
  - 语法：`node --check content.js`（popup.js / background.js 同理）
  - 行为：`node tests/blocker-harness.mjs` —— 全绿表示规则匹配、点选、补位、暂停等行为未回归；故意改坏某处再跑一次应当报错，说明断言没白写
  - 图标：`python tools/gen_icons.py`（重绘到 `icons/`，也可传参输出到别处）
- **一键打包**：双击 `一键打包.bat`，或命令行 `python tools/package.py`（`--skip-tests` 跳测试、`--out 目录` 指定输出）。流程＝语法检查 → 集成测试 → manifest 与图标校验 → 产出 `dist/web-blocker-v<版本>.zip`；**只装浏览器运行需要的 10 个文件**，tests / tools / 文档不进包，打包后还会回读 zip 校验内容一致。任一步失败都会列出问题并以非零码退出。
- **发布**：推送 `web-blocker-v<版本>` tag 触发发布流水线（`.github/workflows/web-blocker-release.yml`）：GitVersion 校验 → 测试 → 打包 → 创建 GitHub Release。**发布说明自动取自 `CHANGELOG.md` 对应版本小节**（`scripts/versioning.py` 生成 `RELEASE_NOTES.md`），小节缺失或为空会直接让发布失败——以此强制「每次改动必留记录」。
- **纳入 git**：

  ```bash
  cd web-blocker
  git init
  git add .
  git commit -m "init: 网页屏蔽器 v1.4.6"
  ```

  `.gitignore` 已备好：编辑器目录、系统垃圾文件、`*.zip` 打包产物、`icons/preview-sizes.png` 预览图都不会进仓库，图标本体不受影响。
