# 更新日志

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 格式，版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [1.4.4] - 2026-11-03

### 修复

- **弹窗「全局启用」开关点不动**：开关外壳误用了 `<span>` 而不是 `<label>`，checkbox 又被 CSS 压成 0×0 全透明——HTML 中只有 `<label>` 会把点击转发给关联控件，所以点击滑块永远不会触发 `change`，开关自 1.4.0 起形同虚设。改回 `<label>` 包裹并补 `cursor: pointer`。此问题为 1.4.0 引入的历史遗留，非 1.4.3 改动引入。

## [1.4.3] - 2026-11-03

修复 5 个影响屏蔽正确性与数据安全的 BUG（含一个让「重新应用」按钮在真实浏览器中必然报错的通道问题），并提升选择器在现代站点（Tailwind 等含特殊字符 class）上的稳定性。

> 版本号说明：1.4.1 / 1.4.2 两个标签此前被用于验证 tag 触发的发布流水线（当时 manifest 仍为 1.4.0），号段已占用，故本次功能发布从 1.4.3 起。

### 修复

- **↑/↓ 微调误删选区**：选中叶子节点按 ↓（没有子元素可走）、或选中已到顶的元素按 ↑（父级是 body）时，当前选中区域会被从选区里静默删掉；现在移不动就保持原选择不变。
- **「真删除节点」模式下 grid 留白永不回收**：此前先删节点再补位，补位的「是不是 grid 第一个子元素」判断永远失败，固定轨道收不回；改为先补位再隐藏 / 删除，两种模式行为一致。
- **动态页面漏屏蔽**：apply 后 600ms 节流窗口内的 DOM 变更会被直接丢弃且不再补跑，SPA 站点在窗口内插入的匹配内容会一直显示；改为顺延到窗口边缘补跑一次。
- **弹窗「重新应用」必然报错 + 显示旧命中数**：该消息的处理是异步回包却没保持消息通道（未 `return true`），真实浏览器里弹窗只会收到「端口关闭」错误；同时统计在 apply 真正执行前就已回包。现在同步应用、返回最新命中、并保持通道。
- **多标签页并发写规则互相覆盖**：规则的新增（点选入库）与弹窗的启停 / 删除 / 导入 / 清空各自 get→改→set，两个页面同时写就会用旧快照覆盖对方，规则静默丢失。所有写操作改为经 background 的串行队列落盘，任何时刻只有一个「读改写」在进行。

### 变更

- 补位改动现在连 `!important` 优先级一起备份与还原；此前原内联样式带 `!important` 时，停用规则后还原的样式优先级变弱，可能被页面样式表覆盖。
- class 选择器一律经 `CSS.escape` 转义：`sm:w-1/2`、`md:block` 这类含 `: /` 的 Tailwind class 不再被判为「不可用」而退化成脆弱的结构路径。
- 弹窗所有规则写操作（启停 / 模式 / 补位 / 删除 / 导入 / 清空）改经 background 串行队列，回包即为最新规则全集，本地不再整组回写旧快照；导入按后台实际新增数报告，缺 `id` 的规则按无效处理。
- 弹窗写入失败时把控件（启用 / 模式 / 收回留白）回滚到改动前状态，避免界面与存储脱节；后台写队列执行失败时明确回包报错，调用方不再空等消息端口超时。

### 质量

- 假 DOM 集成测试新增 6 组：↑/↓ 边界保护、remove 模式 grid 轨道回收、节流窗口顺延补跑、「重新应用」返回最新命中、补丁 `!important` 还原、特殊字符 class 的转义生成与命中；其中前三个修复各自通过变异测试（还原旧实现后断言必然失败）验证有效。
- 假 DOM 基础设施升级：`Style` 支持属性优先级、`matchSimple` 支持选择器转义序列、假 `MutationObserver` 可捕获回调手动触发、假 `chrome.runtime.sendMessage` 模拟 background 串行写队列。

## [1.4.0] - 2026-10-27

点选支持**多选**：按住 Ctrl 单击可连续追加区域，一次确认屏蔽散落在页面各处的多块内容。

### 新增

- **Ctrl（Mac 为 Cmd）+ 单击 = 追加 / 移除**：普通单击仍是"选中 / 换成新区域"；按住 Ctrl 单击未选区域则追加进选区，对已选区域再按 Ctrl+单击则移除。选错一块不用重来。
- **多区域实线框**：每个已选区域都有独立的实线高亮框，最后操作的一块颜色更深（标示"当前活动块"，↑↓/Alt 只作用于它）；鼠标悬停处始终有虚线预览框跟随。
- **确认条汇总**：摘要行显示「已选 N 个区域：选择器1、选择器2…」；「同时屏蔽同类」改为按全部选区合计提示"勾选后约屏蔽 N 个"，任一选区存在可安全批量的同类元素即可用。
- **合并为一条规则**：多区域确认后写入同一条规则，选择器自动去重；规则标签标注「N 个区域 · 首个选择器」，弹窗里仍按单条启停 / 删除 / 暂停。

### 变更

- 高亮框改为按需增减的元素池，数量始终与选区一致；退出点选 / 确认 / Esc 时全部随确认条一起移除。
- `Enter` 确认条件从"已锁定"改为"选区非空"；空选区按确认会得到明确提示「还没选中任何区域」。
- 确认条底部操作提示更新为多选语义：`单击选中（再点别处 = 换成新区域）· Ctrl+单击 追加 / 移除 · …`。
- 确认时先对选择器去重再入库，避免同一区域被重复屏蔽。
- `↑`/`↓`/Alt+点击 改为**优先作用于鼠标悬停的那块已选区域**（悬停处不是已选块时回落到最后点击的块），多选后可以逐块微调，不必按添加顺序来。
- README 新增「使用示例」：以知乎首页三区域（横幅 + 左栏 + 推荐列）为例，逐步列出操作、页面反馈与最终生成的规则形态。

### 质量

- 假 DOM 集成测试新增：追加 / 移除 / 再追加、普通单击整体替换、两区域合并规则的 selectors 顺序（唯一定位 + 同类批量去重）、命中数按并集计算（3 卡片 + 1 广告位 = 4 处）、多选标签格式、批量总数提示。并通过变异测试（禁用 Ctrl 分支）确认「Ctrl+单击应追加区域」等断言有效。
- 仓库化整理：随项目附带 `.gitignore`、图标生成脚本 `tools/gen_icons.py` 与测试套件 `tests/blocker-harness.mjs`（路径改为相对项目，可独立运行），README 增补「项目结构与开发」；扩展源码目录可直接 `git init` 使用。
- 新增一键打包：`tools/package.py` / 双击 `一键打包.bat` —— 语法检查（node --check）→ 假 DOM 集成测试 → manifest 与图标引用校验 → 产出 `dist/web-blocker-v<版本>.zip`。zip 只含浏览器运行所需文件（tests / tools / 文档不进包），打包后回读 zip 逐项比对；任一步失败列出问题清单并以非零码退出。支持 `--skip-tests` 与 `--out 目录`。

## [1.3.0] - 2026-10-27

新增「收回留白」补位：屏蔽区域后自动清掉父级为它预留的空间，其余内容左移 / 上移补位，不再浪费版面。

### 新增

- **补位（收回留白）**，默认开启，屏蔽后立即执行，逐层往上找第一处明显是为该元素预留的空间并清零：
  - 父级的 `padding-left` / `margin-left` / `padding-right` / `margin-right` / `padding-top` / `margin-top` / `padding-bottom`
  - 父级是 grid 且写了固定轨道时，把对应轨道改写成 `0px`（`grid-template-columns: 220px 1fr` 里那一列不会因元素消失而塌掉，这是「隐藏后仍有空白」最常见的原因）
  - 父级自身为 `position: fixed / absolute` 且带 `left` / `top` 偏移时清掉偏移
- **保守阈值**：预留值需 ≥ `max(32px, 被屏蔽块对应边的 65%)` 才动手，且只处理找到的第一层，避免把正常的设计留白一并抹掉。
- **每条规则可单独开关补位**：点选确认条新增「收回留白」勾选（默认勾上），弹窗规则行也有同名复选框。
- 补位改动全部备份原值，与隐藏 / 真删共用同一套还原逻辑：停用规则、快捷键暂停、删除规则、全局关闭都会逐条复原。

### 变更

- 弹窗里模式选项文案改为「隐藏（会收拢）」与「真删除节点」，明确 `display:none` 本身就会让普通流内容收拢——留白来自父级预留，而不是隐藏方式。
- 尺寸与父级引用在隐藏**之前**采集：`display:none` 之后元素的 rect 与 grid 已用轨道值都取不到。
- `MutationObserver` 忽略自己刚补丁过的祖先节点，避免补位触发的样式变化引起重算循环。
- 旧规则（没有 `reflow` 字段）默认按「开启补位」处理，导入的历史规则无需重建。

### 已知局限

- 改写 grid 轨道会把剩余轨道的 `1fr` 固化成当前像素值，窗口大幅缩放后该列不再自适应；此时可改用「真删除节点」或关闭补位。

### 质量

- 假 DOM 集成测试新增：grid 固定轨道塌成 `0px 900px`、父级 `padding-left` 清零、40px 正常留白不被误清、`reflow:false` 时不动父级、清空规则后逐条还原、老规则（无 `reflow` 字段）默认补位。并通过三处变异测试（去掉 grid 改写、去掉 padding 回收、把阈值降到 0.01）确认这些断言有效——其中阈值变异正是被「正常留白不该被误清」这条抓出来的。

## [1.2.0] - 2026-10-27

修复点选「选不中就没法确认」的交互问题，改为预览 → 锁定两段式，并补上键盘微调。

### 修复

- **单击不再只是 hover 跟随**：此前鼠标移动会持续改选目标，把鼠标移向「确认屏蔽」按钮的路上，选择就被沿途元素抢走，导致无法完成确认。现在**单击即锁定**（实线），锁定后无论鼠标移到哪儿，选择都保持在锁定的那一块。
- 未锁定（仅预览）时「确认屏蔽」按钮置灰不可点，避免确认到一个自己没留意的元素。

### 新增

- **`↑` / `↓` 键盘微调**：在锁定目标上向上选父级容器、向下进入第一个子元素，从一张卡片放大到整个卡片列表（或反过来）不用跟嵌套结构较劲。
- **Alt + 点击**：已锁定时等价于 `↑`（原地升一层，不会改选到鼠标下的元素）；尚未锁定时直接锁定鼠标所在元素的父级。
- **`Enter` 确认**：等同点「确认屏蔽」；`Esc` 取消不变。
- 确认条底部新增一行操作提示，说明锁定语义与全部按键。

### 变更

- 高亮框用**虚线 + 浅底**表示预览、**实线 + 深底**表示已锁定，状态一眼可辨；摘要行前缀相应显示「预览：」或「🔒 已锁定：」。
- 再点页面其他位置 = 重新锁定到新元素，行为与提示文案一致。
- Console 的注入日志改为完整操作序列：`移动预览 → 单击锁定 → ↑↓/Alt+点击 微调 → Enter 确认 / Esc 取消`。

### 质量

- 假 DOM 集成测试新增：预览态不可确认、锁定后 hover 其他元素不改变选择、`↑`/`↓` 上下移、已锁定时 Alt+点击升层而非改选、`Enter` 确认入库的目标与微调结果一致。并通过两处变异测试（删掉锁定守卫、禁用 Alt 升层）确认这些断言有效。

## [1.1.0] - 2026-10-27

新增快捷键暂停，不用打开弹窗就能临时放行某个页面的屏蔽规则。

### 新增

- **`Alt+Shift+B` 暂停 / 恢复当前页面**：临时性质，只作用于当前这份文档，刷新或重新打开页面后自动恢复屏蔽。适合「就想临时看一眼被挡掉的内容」。
- **`Alt+Shift+S` 暂停 / 恢复整个站点**：持久性质，写入 `storage.pausedSites`，切到该站任何页面都保持暂停。适合「这段时间这个站先别动」。
- **`background.js` 后台服务脚本**：接收 `chrome.commands` 命令并转发给当前标签页；维护图标角标。
- **图标 ⏸ 角标**：处于暂停状态时扩展图标显示红色 ⏸。角标状态由页面脚本上报（`blk:state`），页面重载后由脚本重新上报，不会出现角标残留。
- **页面左下角提示条**：快捷键触发时弹出两秒提示并写明恢复方式（弹窗此时已关闭，必须有页面内反馈）。
- **弹窗「暂停本页 / 暂停本站」按钮**：与快捷键完全等效，暂停中按钮文案自动变为「恢复本页 / 恢复本站」，状态行显示「本页已暂停 + 本站已暂停」。
- **弹窗「已暂停站点」列表**：列出所有处于暂停状态的站点，点站点名后的 ✕ 即可恢复，不必先导航到那个页面上操作（新增 `blk:setSitePaused` 消息）。
- **`blk:ping` 扩展返回字段**：新增 `tabPaused`、`sitePaused`、`pausedSites`，弹窗可完整还原暂停状态。
- 工具栏图标悬停提示补充快捷键说明。

### 变更

- 暂停判断收进 `ruleMatches()`：任一暂停生效时该站点的规则不再进入应用流程，`activeRules()` 归零，页面立即整体还原（真删模式下被摘掉的节点会插回原位）。
- 用户主动触发的暂停/恢复走同步 `apply()`，不再经过 150ms 防抖，按下即见效。
- `MutationObserver` 现在会跳过扩展自身插入的提示条、点选遮罩与样式节点，避免自我触发多余重算。
- `storage.onChanged` 增加对 `pausedSites` 变化的响应，多标签页之间状态一致。

### 性能与质量

- 无匹配规则（含被暂停）的页面依旧不挂 `MutationObserver`、不做 DOM 扫描。
- 假 DOM 集成测试新增暂停相关断言：暂停即时还原、提示文案、后台状态上报、恢复后重新屏蔽、站点级暂停在重新扫描后仍保持、暂停时生效规则数归零、暂停其他站点不误伤当前站点；并通过删除暂停判断的变异测试确认这些断言有效。

### 升级注意

- 本版新增了 `commands` 声明与后台脚本，**覆盖文件后必须在 `edge://extensions` 点「重新加载 ↻」**，快捷键才会注册。
- 若 `Alt+Shift+B` 无响应，到 `edge://extensions/shortcuts` 查看绑定是否被 Edge 自身或其他扩展占用；可先用弹窗按钮验证功能本身正常。

## [1.0.0] - 2026-10-27

首个版本。

### 新增

- **点选屏蔽**：页面内高亮 → 单击锁定 → 底部确认条；按住 `Alt` 点击可选父级容器。
- **同类批量**：自动识别同一父级下结构相同的兄弟节点，勾选后一并屏蔽；批量选择器强制校验「命中 ≥2 且全部落在同类集合内」，不满足则自动禁用该选项。
- **两级作用域**：整站生效（默认）或仅当前网址（`origin + pathname`）。
- **两种模式**：隐藏（`display:none`，默认）与真删除节点；真删除在规则停用/删除时会把节点插回原来的位置。
- **选择器分级生成**：`#id` → `tag[data-*]` → 可读 class → 哈希 class 组合 → 结构路径兜底。
- **规则管理**：单条启停、模式切换、删除，显示「命中 N 处 / 当前页面未命中」，全局启用开关，JSON 导入导出，清空本站规则。
- **安全护栏**：选择器命中 `body` / `html` 时跳过；SPA 路由变化与局部渲染自动重算。
