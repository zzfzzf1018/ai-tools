# 知乎侧边栏隐藏（Edge / Chrome 扩展）v1.1.0

隐藏知乎网页版新增的左侧图标栏，并让主内容自动补位。纯本地扩展，不联网、不采集数据。

v1.1.0 主要变化：加了**「点选侧栏」**（自动识别没命中时，你在页面上点一下就永久锁定）、改用 `storage.local`（不依赖账号同步）、样式改为脚本内注入（不依赖 Edge 对 manifest `css` 的支持）、并修掉一个会让页面脚本失联的存储监听 bug。

## 安装

1. 把 `zhihu-sidebar-hide` 文件夹放到固定位置，例如 `D:\edge-extensions\zhihu-sidebar-hide`。
2. Edge 打开 `edge://extensions` → 左下角开「开发人员模式」。
3. 点「加载解扩展」选中该文件夹。
4. 知乎页面按 `Ctrl+Shift+R` 强刷。

**更新过文件后**：必须在 `edge://extensions` 里点这张卡片上的「重新加载 ↻」，再回知乎页面强刷一次。只刷页面不会加载新代码——这是最常见的「装了没用」原因。

## ① 点选侧栏（推荐先用这个）

自动识别是按几何特征猜的，知乎真实结构可能对不上。点选模式不猜：

1. 在知乎页面点工具栏扩展图标 → 点「① 点选侧栏」。
2. 鼠标移到左侧图标栏上，会出现蓝色高亮框（框的是整个侧栏容器，不是单个图标）。
3. 单击 → 侧栏立刻消失，选择器自动写进输入框并永久保存。
4. 按 `Esc` 可取消。

生成选择器时会优先用 `#id`、`data-*` 属性、可读 class（`AppAside` 这种），自动跳过哈希 class（`css-1q2w3e`）；实在没有稳定特征才退回 `body > div:nth-child(2) > ...` 结构路径。

## 排障：三步定位

**第一步，确认脚本有没有注入。** 知乎页面按 `F12` → Console，找这一行：

```
[zsh] 知乎侧边栏隐藏 v1.1.0 已注入（弹窗里可点选侧栏）
```

- 没有这行 → 扩展根本没跑：确认地址是 `*.zhihu.com`、扩展卡片是启用状态、点过「重新加载 ↻」、页面强刷过。
- 有这行 → 进第二步。

**第二步，看弹窗顶部状态行。** 显示「页面脚本 v1.1.0 · 当前隐藏 N 个元素」：

- `N = 0` → 自动识别没命中，直接用「① 点选侧栏」。
- `N ≥ 1` 但侧栏还在 → 隐藏的是别的元素，点「② 自动识别」看它到底锁了谁，把「清空自定义」清一下再重点选。

**第三步，布局难看就关补位。** 侧栏没了但正文偏左/偏右 → 关掉「主内容自动补位」开关，只藏栏不动布局。

## 它怎么自动认这个侧栏

知乎改版后 class 名基本是哈希的，写死选择器一改版就废，所以自动识别用几何 + 结构特征：贴左 ≤40px、宽 ≤200px、高 ≥视口 30%、`fixed`/`sticky`/`absolute` 或横向 flex/grid 首个子元素、含 ≥3 个 `a`/`button`/`svg`/`img`/`li`、文本 <300 字符、且不含 `main`/`article`。命中后挂 `data-zsh-hide`（`display:none`），再往上找第一层 `padding-left`/`margin-left ≥ 24px` 的祖先清掉收回留白，最后正文中心明显偏离时补 `margin-inline:auto`。知乎是 SPA，所以挂了 MutationObserver + `popstate`/`hashchange` + 2 秒兜底，并做了防抖避免自触发死循环。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单，只在 `*.zhihu.com` 注入，仅申请 `storage` 权限 |
| `content.css` | `[data-zsh-hide] { display: none !important; }`（脚本内也会注入一份，双保险） |
| `content.js` | 识别 / 隐藏 / 补位 / 点选锁定 / 选择器生成 / SPA 重算 |
| `popup.html` `popup.js` | 开关、点选、自动识别诊断、自定义选择器 |

## 想彻底停用

`edge://extensions` 里移除即可。扩展只在运行时改内联样式和属性，刷新即恢复，不会在知乎留下任何持久改动。
