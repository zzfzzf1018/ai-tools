# People Requirements Records

Create one Markdown file for each user task in this directory, using the next unused numeric prefix, for example `0001-short-title.md`. Keep the user's request and material interaction decisions together in the same record. If two tasks choose the same number, use the next unused prefix.

Each record should include:

- Date and concise task title.
- The user's request, preserving its language and meaning.
- Decisions and clarifications that materially shaped the task.
- Final acceptance criteria or outcome when known.

Redact secrets, credentials, private keys, tokens, and sensitive personal information. Do not copy unrelated chat, hidden reasoning, or internal analysis. Use explicit redaction markers where needed.
