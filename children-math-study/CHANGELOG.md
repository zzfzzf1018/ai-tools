## [1.2.0] - 2026-11-07

错题同类题自动变形再练、星星商店 / 头像装扮与勋章扩展。

### 新增
- **错题同类题自动变形再练**（`js/variants.js`）
  - 两条生成路径：题干含标准算式时**保留原有措辞、只替换数字**（`A op B = ⬜` / `A op ⬜ = C` / `⬜ op B = C` 三种模式）；情景题则从「题干数字 ↔ 原题答案」反推**唯一**算术关系，用同一关系换一组数字重算答案，公式有歧义一律放弃，绝不生成错题
  - 无法直接变形的题按「课程知识点 + 年级」映射到同结构生成器（加减乘除、凑十、小数、分数、因数、方程、平均分、比大小、数数），自动带干扰项与两级提示
  - 全库 312 题中 **94 道可直接变形（30.1%，其中 41 道为情景题语义反推）**，其余按知识点生成
  - 入口：错题本每条「🔁 变式」弹层（4 题）、错题本「全部错题 · 同类题变式训练」独立页（最多 10 题）、首页「变式再练」
  - 变式全对给对应错题记一次「巩固」，连对两次仍会自动飞走；变式题走 `transient`，不污染错题本
- **星星商店 / 头像装扮**（`js/shop.js`）
  - 8 款头像 + 8 款挂件，用累计星星兑换；余额 = 累计星星 − 已消费，重玩刷新更高星级会自动增加余额
  - 已解锁装扮可随时免费换戴；顶栏头像按钮、首页形象、通关奖状、家长档案全局展示
  - 购买即时检查新勋章；家长视图小档案可直达商店
- **勋章扩展**：6 枚 → 12 枚，新增「听算小耳朵 / 七日坚持 / 单元小测王 / 变式小能手 / 装扮收藏家 / 星星大王」；练习、变式与兑换完成后即时结算，不再只等通关
- 家长视图新增变式训练统计与当前形象；重置进度保留姓名，装扮随钱包恢复默认

### 修复 / 加固
- 练习 / 变式 / 兑换结算后即时发放勋章（原先仅在通关结算时检查）
- 存档新增 `wallet` / `player.accessory` / `stats.variant*` 字段并逐字段兜底；重复购买、余额不足、脏钱包均安全

### 验证
- `npm run verify`：**168 项全过**（新增变形公式正确性、全库覆盖率、商店购买/佩戴、扩展勋章条件等断言）
- `npm run e2e`：**52 项断言全过、0 JS 错误**（新增变式页、单题变式弹层、商店兑换与头像同步）

## [1.1.0] - 2026-11-07

题目语音播报全覆盖、按单元递进的学习路径，以及配套练习中心。功能级更新，升 minor。

### 新增
- **全链路语音播报**（`js/speech.js`）：题目、选项、数字卡、提示、故事分镜、探索要求与结论、结算语均可朗读；使用系统本地中文 TTS（Web Speech API），完全离线、无素材、不联网
  - 朗读文本清洗：emoji/HTML 去噪，`+ − × ÷ = > <` 转中文、`⬜`→「几」、`3.14`→「三点一四」、`1/2`→「二分之一」
  - 每题工具条：🔊 读题目 / 🔢 读选项 / 🔢 读数字卡 / 🔁 再听一遍 / ⏹ 停止；进入题目自动读一遍
  - 顶栏 🔊 一键开关；家长视图可调总开关、自动读题、读选项、语速（0.6~1.4×）、音色、试听
  - 不支持 TTS 或本机无中文语音时自动降级并给出提示，绝不阻断学习
- **按单元递进**：年级 → 学期 → 单元 → 课程展平为一条连续学习路径（`Data.pathOf`），完成上一课才解锁下一课，**跨单元、跨学期同样生效**
  - 年级页新增学习路线横幅（当前学期/单元、下一课、总进度、继续闯关直达）
  - 单元卡片新增「第 N 单元」序号、状态徽章（未解锁/新单元/学习中/已通关）、进度条、锁定提示
  - 单元全部通关后颁发「单元通行证」，开放单元综合小测
  - 首页年级卡显示当前所处单元；家长视图新增单元掌握度清单
- **每日口算挑战**：按年级动态生成（5/10/20 题），5 个年级各有专属题型池，自动生成干扰项与两级提示；结算含正确率、用时、连续打卡
- **🎧 听算模式**：题目只播报、不显示文字，全部改为输入题练心算；语音不可用时自动退回显示题目，并支持「👀 显示题目」兜底
- **单元综合小测**：从单元各课抽题组卷（最多 10 题），按错题数给 1~3 星，成绩存档可复测
- **错题一键组卷**：错题本抽取最多 10 题组成一套卷，答对两次仍会自动移出错题本
- **家长成长报告**：连续打卡、累计答题、首次作答正确率、今日答题、近 7 日练习量柱状图、各年级当前进度、单元掌握度
- **小档案**：可修改奖状上的孩子名字；首页新增「今日冒险」入口区（每日口算 / 错题组卷 / 单元小测 / 成长报告）

### 修复 / 加固
- **解锁逻辑缺陷**：原 `renderGrade` 每个单元都把 `prevDone` 重置为 `true`，导致第 2 单元、第 2 学期的第一课无需前置课程即可进入；改为由全年级连续路径统一判定
- 每日口算与小测走 `transient` 模式，不写入错题本、不消耗错题连对次数；错题组卷按题目自身的 `lessonId` 归属，跨课组卷不再串课
- 答题统计只计每题首次作答，连点错误选项不会拉低正确率
- 切题、换页、阶段切换时统一停止朗读，避免跨页串音
- 换页时清理未触发的自动播报定时器；`localStorage` 写入失败（隐私模式等）降级为会话内有效
- 家长视图薄弱点题目文本改为转义输出

### 封板前深度复审（第二轮）
逐文件通读 + 独立只读审查 + 真实浏览器交互测试，修复 4 类会让孩子卡住的严重缺陷与 10 类状态一致性问题：

- **听算无声会卡死**：原来只在「语音不可用」分支给「👀 显示题目」出口；若 API 存在但系统无语音、静音、播报被策略拦截，题干被隐藏且无出口。现在只要有可用语音才隐藏题目（`Speech.canAural()`），朗读失败自动显示题目，且**任何情况下**听算工具条都保留显示题目按钮
- **脏存档导致错题重做弹层永久锁死**：弹层无关闭按钮，缺答案/缺选项的旧题无法作答。现在弹层有 ✖ 与 Esc 出口；`Game.mount` 新增 `normalizeQuestion` 题目守卫（缺答案丢弃、结构不符降级为可作答选择题、所有文本统一转义）；错题本快照在存档层逐字段收敛
- **`unitQuiz.stars` 脏值令页面白屏**：负数/巨值传给 `'⭐'.repeat()` 抛 RangeError。现在存档归一化把星级夹到 0~3，所有 `repeat` 处再做二次夹取
- **答题统计口径错**：先错后对会记 2 笔，正确率虚高。现在每题只在第一次作答时记一笔
- 其他：结算异步期间切页不再往游离节点渲染；`voiceOK` 改为实时判定（顶栏开关后状态同步）；换页统一释放键盘/拖拽监听与残影；拖放 ghost 首帧 `NaNpx`、同一筹码跨槽移动留下脏数据修正；答错后改对时进度点不再残留红色；提示自动朗读跳过最后一条讲解避免泄题并做连点节流；单元小测按课程数自适应抽题（单课单元也能凑够 8 题）；首页已测单元仍可复测；space 主题亮底白字改为深色；重置进度保留孩子姓名；`localStorage` 写失败降级；图形选项朗读改为读数量
- 兼容性说明：v1.0 存档若出现「后面的课已完成、前面的课未完成」，v1.1 连续解锁会推荐先补前面未完成的课，属预期行为，不影响已获得的星星

## [1.0.1] - 2026-11-03

封板前的缺陷修复与稳定性加固。

### 修复
- **四年级「10 个一千万」题无法作答**：数字键盘只能输入数字，汉字答案永远判错并锁死后续课程，改为选择题
- **数轴探索在小数刻度卡死**：`0 + 7×0.1` 得 `0.7000000000000001`，与目标 0.7 严格相等永不成立（四年级「认识小数」、五年级「小数除法」两课直接卡死，五年级「分数加减」的 0.25 步长一并加固），改为按步长精度取整 + 容差判定
- **天平探索浮点误差**：配重含 0.1 时累加误差可能导致永远不平衡，改为容差比较
- **拖放题答错后误判**：清空槽位写空串但判空用 `!= null`，此后每次落子都会提前判错并扣星，改为空串判定
- **连点「确认」重复计分**：答对后 900ms 内可再次提交，会把同一题算两次并跳题，改为答对即锁定本题
- **返回键失效**：hash 实际为 `#/lesson/...`，判断用了 `#lesson/`，导致从课程页返回总是回首页
- **深链刷新丢位置**：启动时 `slice(1)` 拼出 `#//lesson/...` 导致解析失败，改为统一路由解析
- **非法链接白屏**：访问不存在的年级/课程 id 时页面空白，改为回退首页
- **错题重做无法完成**：非数字答案用 `parseFloat` 比较永远判错；选择题只能手打文字，改为按题型渲染选项，且重做后整页刷新避免列表重复叠加
- **错题本连击逻辑**：再次答错未清零「连续答对」计数，错-对-错-对也会被移出，改为答错清零
- **存档脏数据整页白屏**：`player`/`stars` 被改成 null 等异常类型时崩溃，初始化时做类型兜底
- **离开页面后弹勋章/走定时器**：切换路由后延迟任务仍在执行，改为校验节点是否仍在页面中

### 安全
- 错题本与重做浮层中的题目文本改为转义输出，避免本地存档被篡改后注入 HTML

### 验证
- 内容全量校验：30 课 / 312 题，答案存在于选项、排序答案与备选项一致、填空答案可由数字键盘输入、拖放槽位数与答案数一致
- Edge headless 端到端 8 项全通过：深链+返回键、非法课程回退、数轴 0.7（四年级）、数轴 3.6（五年级）、拖放答错清空、错题连对两次移出、一年级第一课完整通关 3 星、家长页/错题本渲染
