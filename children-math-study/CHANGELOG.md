## [1.0.2] - 2026-11-04

体验补强与错题重做修复。

### 修复
- **错题本拖放/排序题无法重做**：重做浮层只支持选择和文本框，改为按原题型复用闯关渲染器，错题可真正重做
- **重复答案拖放题缺筹码**：6 道题（如 `5+8=⬜，5+⬜=10，10+3=⬜`）的答案值重复但备用筹码只有一个，实际无法填满；补齐筹码并在引擎侧做兜底补足
- **同题重复答错重复扣分**：连点错误选项会多次计入错题与扣星，改为同一题只计第一次错
- **错题快照过期**：内容调整后旧存档中的题干/选项可能失效，重做时优先按 lessonId+qid 回源最新题目

### 新增
- 输入题支持实体键盘：数字、小数点、退格、回车
- 结算页增加“下一课”直达；返回地图自动定位上次课程；首页增加“继续上次冒险”
- 已通关课程再次进入时可选“复习一遍”或“直接闯关”
- 探索页增加“跳过探索”，避免卡在互动环节
- 家长视图增加存档导出/导入、重置进度（二次确认）与答题音效开关
- 轻量 WebAudio 答题音效，无需素材，可一键关闭
- 支持系统“减少动态效果”（prefers-reduced-motion）

### 验证
- 内容全量校验：5 年级 / 30 课 / 312 题，0 错误（选项含答案、输入答案可数字输入、拖放/排序筹码充足）
- E2E 17 项全通过：原 8 项 + 错题拖放重做、键盘作答、同题只计一次错、已通关直闯、下一课、继续上次、存档导入/重置、音效开关、跳过探索
- 全部 JS 语法检查通过（node --check）

## [1.0.1] - 2026-11-03

封板前的缺陷修复与稳定性加固。

### 修复
- **四年级「10 个一千万」题无法作答**：数字键盘只能输入数字，汉字答案永远判错并锁死后续课程，改为选择题
- **数轴探索在小数刻度卡死**：`0 + 7×0.1` 得 `0.7000000000000001`，与目标 0.7 严格相等永不成立（四年级「认识小数」、五年级「小数除法」两课直接卡死，五年级「分数加减」的 0.25 步长一并加固），改为按步长精度取整 + 容差判定
- **天平探索浮点误差**：配重含 0.1 时累加误差可能导致永远不平衡，改为容差比较
- **拖放题答错后误判**：清空槽位写空串但判空用 `!= null`，此后每次落子都会提前判错并扣星，改为空串判定
- **连点「确认」重复计分**：答对后 900ms 内可再次提交，会把同一题算两次并跳题，改为答对即锁定本题
- **返回键失效**：hash 实际为 `#/lesson/...`，判断用了 `#lesson/`，导致从课程页返回总是回首页
- **深链刷新丢位置**：启动时 `slice(1)` 拼出 `#//lesson/...` 导致解析失败，改为统一路由解析
- **非法链接白屏**：访问不存在的年级/课程 id 时页面空白，改为回退首页
- **错题重做无法完成**：非数字答案用 `parseFloat` 比较永远判错；选择题只能手打文字，改为按题型渲染选项，且重做后整页刷新避免列表重复叠加
- **错题本连击逻辑**：再次答错未清零「连续答对」计数，错-对-错-对也会被移出，改为答错清零
- **存档脏数据整页白屏**：`player`/`stars` 被改成 null 等异常类型时崩溃，初始化时做类型兜底
- **离开页面后弹勋章/走定时器**：切换路由后延迟任务仍在执行，改为校验节点是否仍在页面中

### 安全
- 错题本与重做浮层中的题目文本改为转义输出，避免本地存档被篡改后注入 HTML

### 验证
- 内容全量校验：30 课 / 312 题，答案存在于选项、排序答案与备选项一致、填空答案可由数字键盘输入、拖放槽位数与答案数一致
- Edge headless 端到端 8 项全通过：深链+返回键、非法课程回退、数轴 0.7（四年级）、数轴 3.6（五年级）、拖放答错清空、错题连对两次移出、一年级第一课完整通关 3 星、家长页/错题本渲染
- 桌面打包复测：electron-builder portable 产物正常

## [1.0.0] - 2026-11-03

首个正式版本：数学奇妙岛 Math Wonder Island。

### 新增
- **五年级全覆盖课程内容**：沪教版一至五年级，每学年 2 学期、共 30 个知识点、312 道原创情景化题目
- **三步学习闭环**：📖 故事引入 → 🧪 互动探索 → 🎮 闯关练习
- **6 种互动探索引擎**（鼠标/触屏通用）：点一点数一数、拖一拖平均分、数轴滑一滑、铺方格（面积）、天平平衡（等量/方程）、十格框凑十
- **4 种题型**：选择、数字输入（儿童键盘）、拖放填空、排序
- **提示阶梯**：答错逐级给提示（情境→分步→讲解），错题自动进错题本，连续答对两次移出
- **成长式双画风**：一二年糖果乐园 / 三年级清新过渡 / 四五年级深空冒险，CSS 变量换肤
- **奖励系统**：星级结算、勋章墙（6 枚）、激励反馈动效
- **家长视图**：总览、各年级完成度、薄弱点分析与一键重学、错题分布
- **进度本地保存**：Electron 走 IPC 写 userData JSON，Web 版降级 localStorage
- **Electron 桌面端**：portable exe 打包配置（electron-builder）

### 验证
- Node 校验：5 个内容文件全部可加载，30 课 / 312 题结构完整
- Edge headless 端到端：完整通关一年级第一课（故事跳过→探索→三关 11 题→3 星结算→地图节点 ✅→下一课解锁），零 JS 错误
- 浏览器实测：首页/年级页/课程页导航、双主题渲染均通过
