## 数学奇妙岛 v1.1.0：语音播报 + 单元递进 + 练习中心

需求：题目全部支持语音播报；每个年级按单元递进；补充可增加的功能。全部已实现并验证。

### 实现要点
- 新增 `js/speech.js`：Web Speech API 系统本地中文 TTS，完全离线。清洗层 `toSpeakText` 处理 emoji/HTML、数学符号中文化、⬜→「几」、小数逐位读、分数中文语序。覆盖题干/选项/拖放数字卡/提示/故事分镜/探索要求与结论/结算/错题本题干/练习中心。顶栏全局开关 + 家长视图（总开关、autoRead、readOptions、语速、音色、试听）；不支持或无中文语音时降级、不阻断。
- 单元递进：`js/data.js` 新增 `pathOf(grade)` 把「学期→单元→课程」展平为连续路径，`unitKey = g{年级}s{学期序号}u{单元序号}`。**修复 v1.0 缺陷**：原 `renderGrade` 每单元重置 `prevDone=true`，导致第 2 单元/第 2 学期首课可直接进入；现由全年级连续路径统一判定解锁。新增 isUnlocked / unitProgress / unitMeta / gradeUnits / allUnitKeys / nextToLearn / unitQuestions / prevLesson。
- 新增 `js/practice.js`：每日口算（按年级动态出题，5 套题型池）、🎧 听算模式（只播报不显示，强制 input，语音不可用自动退回）、单元综合小测（通关后开放、抽题组卷、评星存档）、错题一键组卷。统一复用 `Game.mount`。
- `js/game.js`：新增 `transient`（练习不写错题本）、逐题 `lessonId` 归属（错题跨课组卷不串课）、正式启用 `onQuestionDone`、答题统计只计首次作答、切题停止朗读。
- `js/save.js`：新增 `unitPassed` / `unitQuiz` / `daily` / `stats` 与语音设置项，全部带脏数据兜底；新增 recordAnswer / recordPractice / streak / lastDays / markUnitPassed / saveUnitQuiz / setName / setSpeechSetting；localStorage 写入失败降级。
- `js/parent.js` 重写为成长报告（连续打卡、正确率、近 7 日柱状图、单元掌握度）+ 语音设置 + 小档案 + 原有视图。
- `js/app.js` 重写：新增路由 daily / quiz/<unitKey> / wrong-drill，首页「今日冒险」，年级页学习路线横幅与单元序号/状态/进度/锁定提示，单元通行证入口放在 `js/lesson.js` 结算页。
- CSS 追加 v1.1 组件样式（三主题均用 CSS 变量），index.html 引入 speech.js / practice.js 与顶栏 🔊 按钮。
