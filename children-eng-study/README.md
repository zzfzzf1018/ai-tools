# 🌈 趣味英语乐园 (Kids English Wonderland)

> 面向上海小学一至五年级的趣味英语学习应用
> 全英文图文沉浸 · 分单元闯关 · 标准发音 · 句子小剧场 · 趣味乐园十一玩法 · 六个小游戏 · 连续闯关 · 单文件 Windows 便携版

**当前稳定版：v1.5.1** ・ 仓库：https://github.com/zzfzzf1018/ai-tools/tree/main/children-eng-study ・ 发布：https://github.com/zzfzzf1018/ai-tools/releases

## ✨ 功能特性

| 模块 | 说明 |
|------|------|
| 🗺️ **关卡地图** | 选择年级后先进入关卡地图，展示该年级全部单元、单词总数与关卡进度；每 5 个单词 1 关，全库 229 词拆成 82 关，100% 覆盖，逐关点亮 ✓；自动记住上次年级，直接点「学习」Tab 也能回到地图 |
| 📚 **分级学习** | 一年级到五年级，26 个单元全部改为英文主题；一年级额外「Alphabet Adventure」字母大冒险 |
| 💬 **句子小剧场** | 每个单元 1 个句子关，共 130 条英文句子：看表情小剧场 → 听音/慢速听 → 按顺序点词块拼句 → 高亮目标词 → 大声跟读评星 |
| 🐾 **单词宠物** | 首页常驻，学词 / 通关 / 拼句 / 复习积累 XP，🥚→🐣→🐥→🦜→🦄 五段进化，可用星星喂食 |
| 🔁 **间隔复习** | 「不熟」的词按 1 / 2 / 4 / 7 / 15 天自动排队，首页显示今日待复习数；看图听音选词，走完整轮自动移出错词本 |
| 🔤 **自然拼读** | 10 个音素关：听例词选首字母 → 按字母顺序拼出 CVC 单词（C-A-T → CAT 🐱）并朗读 |
| 📖 **绘本小剧场** | 10 本 Emoji 英文小故事，3 格连环画逐格朗读，最后自己选一个英文结局 |
| 🧩 **句型换词** | 8 个句型，从 3 张图片选一个填进 `I like ___.` 这类句型，自动成句并朗读 / 跟读 |
| 🎵 **韵律儿歌** | 6 首英文 Chant，逐行慢速朗读 + 高亮 + 👏 拍手动画，可停止、重念、换歌 |
| 🎬 **小配音员** | 看 Emoji 场景自由说一句英文并录音，成就页「我的配音集」可回放 / 删除（最多 20 段） |
| 🎧 **磨耳朵听力** | 每日盲听（只听不看、播完揭晓，每天首次发星）+ 听音选图 + 听写填空三种模式 |
| 🎭 **剧情冒险** | 以单词宠物为主角，把每个单元的全部关卡串成章节任务，通关时宠物鼓励、单元全通显示章节剧情 |
| 📕 **弱项专练本** | 把「不熟」的易错词集中成册，每轮最多 12 个专练，页内可直接移出错词本 |
| 🏅 **贴纸收集册** | 26 枚里程碑贴纸（单词量 / 星星 / 连续天数 / 游戏 / 句子 / 朗读 / 关卡 / 各玩法 / 宠物形态 / 盲听 / 专练），达成即解锁，浮动提示 + 集册展示 |
| 🔥 **Combo 连击** | 小游戏连续答对累积连击，≥3 分数 ×1.5、≥6 分数 ×2，顶部实时显示连击徽标 |
| 🗣️ **跟读真实评分** | 语音识别多候选 + 词级匹配，≥80% 三星 / ≥40% 两星 / 其余一星，低分自动播 0.6 倍速慢速示范 |
| 🖼️ **全英文图文卡片** | 每张卡片只有英文单词、Emoji 图片、国际音标与英文例句，**不含任何中文词义** |
| 🔤 **字母大冒险** | 一年级 Unit 0，26 个字母大小写展示、音标、例词、英文例句，专为零基础设计 |
| 🔊 **标准发音** | 基于 Web Speech API，美式英语发音，语速和音调专为儿童调整，600ms 去重防堆叠 |

| ⭐ **收藏 / 不熟** | 卡片上一键收藏或标记不熟，成就页两个 Tab 分别列出，点击直接定位到对应关卡 |

| 🎮 **六个小游戏** | 单词连连看 · 听音选词 · 拼写大师 · 记忆翻牌 · 字母拼拼乐 · **句子小剧场**（新增），全部为英文 + 图片 |

| 💾 **本地持久化** | 学习进度、关卡完成状态、收藏/不熟、录音自动保存到 localStorage，支持 JSON 导出/导入 |
| 🎨 **生动界面** | 漂浮气泡背景、卡片翻转动画、表情弹跳、按钮微交互、键盘焦点高亮 |

### 桌面版使用说明

1. 双击 `Kids-English-Wonderland-1.5.1-x64-portable.exe`
2. 首次启动会解压到临时目录（约 30 秒），后续启动几乎瞬时
3. 未签名：Windows 可能提示"未知发布者"，核对 `SHA256SUMS.txt` 中的校验值后可继续运行
4. 学习数据保存在本机，不会上传任何服务器
5. 发音使用 Windows 内置英语语音（建议设置 → 时间和语言 → 语音中确认已安装英文语音包）

### Web 版使用说明

**方式一**：双击 `index.html` 直接在浏览器打开（最简单）

**方式二**：本地 HTTP 服务器（推荐，语音加载更稳定）

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 📖 学习内容（沪教版风格 · 全英文）

- **一年级 🐣 单词启蒙** — **Unit 0 Alphabet Adventure**（26 字母大小写 + 音标 + 例词）、Greetings、My Family、My Body、Numbers、Animals
- **二年级 🐰 单词乐园** — Colours、School Things、Yummy Food、Toys、My Home
- **三年级 🦊 句型花园** — Hello & Names、My School、Daily Life、Hobbies、Describing Things
- **四年级 🦁 故事森林** — My Room、Weather & Seasons、Sports、Jobs、Travel
- **五年级 🐉 魔法城堡** — Festivals、Our Earth、Shopping、Dreams、Learning

一年级共 6 个单元（含字母大冒险），二~五年级各 5 个单元，每单元 8–10 个单词，含音标与英文例句。
每个单元拆成若干单词关（每关 5 词）+ 1 个句子关（最多 5 句），全库共 229 词 / 130 句 / 82 关，**不含任何中文词义**。

## 💡 使用说明

1. **选择年级**：首页点击对应年级卡片（一年级~五年级），卡片上直接显示该年级单词总数与关卡数
2. **关卡地图**：进入后先看到完整关卡地图，按单元列出所有关卡与句子关，点任意关卡或「▶ 继续闯关」开始学习
3. **单词关（每关 5 词）**：
   - 卡片只显示英文单词 + Emoji 图片 + 音标 + 英文例句，点击卡片或 🔊 再听一遍
   - ◀ 上一张 / ▶ 下一张 切换；最后一张点「完成本关 ✓」
   - 通关弹窗点「▶ 下一关」直接续关，或「🗺️ 关卡地图」自由选关；学完整个年级还能「▶ 下一年级」
4. **句子关 💬**：看表情小剧场 → 🔊 Listen / 🐢 Slow 听句子 → 按英文顺序点词块拼句 → 高亮目标词 → 🗣️ Say it 跟读拿星星 → 下一句 / 完成这一关
5. **趣味乐园**：「📚 学习」页顶部切换玩法 Tab
   - 🐾 首页宠物卡用星星喂食，学习会自动帮它进化
   - 🔁 首页「Today's Review」或玩法 Tab 进入今日复习，答对的错词走完 1/2/4/7/15 天计划后自动毕业
   - 🔤 Phonics / 📖 绘本 / 🧩 句型 / 🎵 儿歌 / 🎬 配音 / 🎧 磨耳朵 / 🎭 剧情冒险 / 📕 弱项专练 / 🏅 贴纸册 均为「英文 + 图片」，不依赖所选年级（剧情冒险按当前年级展开），随时可玩
   - 玩法内点「← 返回」回到关卡地图
6. **玩游戏**：导航到「🎮 游戏」Tab，选择六个小游戏之一；通关奖状上可「▶ 下一关」连续闯关、「🔄 再玩一次」、「🎮 游戏列表」或「🏠 首页」，不必退回主页
7. **成就追踪**：「📊 成就」Tab 查看已学单词数、朗读次数、年级进度、徽章解锁，「🎬 配音」Tab 回放自己的英文配音，并可导出/导入进度 JSON

## 🔧 开发者指南

### 本地开发

```bash
# Web 版：直接打开 index.html，或起本地服务
python -m http.server 8080

# 桌面版：开发模式启动 Electron
npm install
npm run desktop
```

### 本地打包桌面版

```bash
npm install
npm run desktop:runtime   # 首次需要，下载 Electron 运行时
npm run package           # 产出 release/Kids-English-Wonderland-<version>-x64-portable.exe
```

### 自动发布（GitHub Actions）

工作流：[children-eng-study-release.yml](../.github/workflows/children-eng-study-release.yml)

| 触发 | 行为 |
|------|------|
| Pull Request 改动 `children-eng-study/**` | 校验 JS 语法与 manifest |
| 推送 `children-eng-study-v*` tag | 自动打包便携 exe + Web zip → 发布 GitHub Release |

### 发版步骤

**每次改动封板发布新版本，必须先登记变更记录，再升版本、打 tag。**

```bash
# 1. 在 CHANGELOG.md 最上方登记本次变更（格式 ## [版本号] - 发布日期）
# 2. 修改 package.json 的 version（必须与 CHANGELOG 条目、将要打的 tag 三者一致）
# 3. 提交并推送 main
git add children-eng-study
git commit -m "feat(children-eng-study): <变更说明>"
git push origin main

# 4. 打 tag 推送，触发自动发布
git tag -a children-eng-study-v1.5.1 -m "children-eng-study v1.5.1"
git push origin children-eng-study-v1.5.1
```

发版门禁（CI 会自动校验，任一缺失即构建失败）：

- `package.json` 版本 = tag 版本
- `CHANGELOG.md` 存在 `## [版本号] - 日期` 条目
- Release 说明由 CI 从 CHANGELOG 该条目自动生成（`scripts/release-notes.sh`）
- 如已发布版本的说明需要修正，在 Actions 页手动运行本 workflow（输入 `tag`），仅刷新发布说明，不重新打包

### 版本号规则

- 任何变更都需升级版本号，**不允许删除已发布的 tag**（GitHub Ruleset 已强制开启）
- **Patch（x.y.Z+1）**：无功能改动、文档、构建/CI 修复、依赖升级
- **Minor（x.Y+1.0）**：小功能新增、内容扩充（如新增单元/单词）
- **Major（X+1.0.0）**：架构调整、破坏性变更

历史已发布的 tag 均不可删除或移动，如需修正发版问题请升 Patch 版本。
