# 变更记录

本文件是本项目**唯一**的变更记录来源。每次封板发布前必须先在此登记对应版本条目，
CI 会把该条目自动写入 GitHub Release 说明（`## [X.Y.Z] - YYYY-MM-DD` 为版本标题）。

格式约定：

- 版本标题固定为 `## [版本号] - 发布日期`（方括号与空格不可省略，CI 依赖此格式提取）
- 新版本追加在最上方，按时间倒序排列
- 条目使用 `✨ 新功能` / `🐛 修复` / `🎨 界面` / `🔧 构建与 CI` / `📝 文档` / `♿ 无障碍` 前缀

## [1.6.0] - 2026-11-07

✨ 题目语音小助手 + 章节递进式冒险地图（让题目会说话，让课程一关一关往下走）

> `schemaVersion` 保持 **6**，旧存档无需迁移。新增的「题目语音引导」开关存放在独立的语音设置里，不影响学习进度数据。全库仍为「英文 + 图片」沉浸模式，不含任何单词中文词义。

### ✨ 新功能 · 题目语音小助手（VoiceGuide）

- **✨ 六道题全部会说话**：连连看 / 听音选词 / 拼写大师 / 记忆翻牌 / 字母拼拼乐 / 句子小剧场统一新增「语音小助手」播报条，用活泼的英文读出题目指令（如 `Listen carefully, then tap the right one!`），旁边有 🔊「再听一遍」，随时可重听整道题
- **✨ 读题 → 读单词 → 读例句自然连读**：借助浏览器原生朗读队列（`SpeechHelper.speak` 新增 `queue` 选项），一次播报把「题目指令 + 目标单词 + 例句」依次念完，不额外引入定时器，切页时随 `SpeechHelper.stop()` 一并安静下来
- **✨ 情绪化语音反馈**：答对从 10 句表扬语（`Great job!` / `Super star!` / `High five!` …）随机选一句并自动避开上一句，再用更高音调复读刚学会的单词巩固；答错从 5 句温柔鼓励语（`Try again, you can do it!` …）中选一句并重读目标单词，不再只有单调的 `Correct!` / `Try again!`
- **✨ 点什么就念什么**：连连看点英文或点图片、记忆翻牌翻到任意一张卡，都会立刻念出对应单词，帮孩子把图像、文字和声音连起来
- **✨ 通关有庆祝语音**：游戏奖状弹出时说一句随机庆祝语；整个章节通关打开宝箱时再额外庆祝一次并撒更多纸屑
- **✨ 学习卡片与句子关也有小老师**：单词卡自动播报升级为「题目指令 + 单词 + 例句」三段连读；句子小剧场新增可点播报条，重听「题目指令 + 完整句子」
- **✨ 家长可单独关闭**：设置面板新增「题目语音引导」开关，关掉后读题、表扬、庆祝全部静音，但单词发音按钮、慢速朗读、跟读评分照常可用；设置会随「导出进度」一起带走

### ✨ 新功能 · 章节层层递进的冒险地图

- **✨ 课程按 Chapter 顺序推进**：每个年级的词库改为「Chapter 1 → 2 → 3 …」的冒险章节，前一章所有关卡通关才点亮下一章；地图顶部有章节旗帜路径与「下一站 · Step N/总关数」引导，孩子永远知道接下来该学哪一关
- **✨ 单元变成有故事的地方**：26 个单元各配一句英文故事导语和一处冒险地点（如 `🌈 Letter Land · Meet 26 little letter friends!`、`🚀 Star Ship · Dream big and reach for the stars!`），五个年级各有自己的冒险主题和动物伙伴
- **✨ 阶梯式关卡节点**：每章的 L1 → L2 → … → 💬 Sentence Boss 用上下错落的小台阶串成一条往上爬的小路，节点标出步数；已完成打 ✓，当前关高亮脉冲并站着宠物伙伴，未解锁显示 🔒

- **✨ 章节宝箱**：一章全部通关即开宝箱 +5⭐，卡片变绿、旗帜换成 🏁、宝箱弹跳，通关弹窗改为「🎁 Treasure Unlocked!」并提示下一章已点亮

### 🐛 封板终审追加修复（真实语音合成模拟 + 故障注入）

- **🐛 语音合成失败会产生未处理的 Promise 拒绝**：`SpeechHelper.speak()` 的 `onerror` 对 `synthesis-failed` / `network` 等错误执行 `reject(e)`，而绝大多数调用方（含 v1.6.0 新增的 8 处读题/反馈）不会写 `.catch()`，浏览器控制台报错、Electron 可能弹未捕获异常。现错误与主动中断统一静默 `resolve()`，与「不支持时静默结束」的注释契约一致；依赖 `speak().then()` 推进的盲听流程也不会被卡住
- **🐛 题目播报条与单词卡并排挤压**：`cardContainer` / `sentenceStage` 都是横向 `flex`，把播报条作为子元素插进去会与卡片并排，卡片被压缩变形。新增独立静态容器 `#learnGuideBar`，由 `App.renderLearnGuide()` / `hideLearnGuide()` 统一管理；回关卡地图、切玩法、未选年级空态、切关卡时都会正确收起，游戏页仍使用自己的 `#voiceGuideBar`
- **🐛 词汇/句子不足提前 return 时留下一个可见的空播报条**：`startGame` 原先先把游戏页播报条设为可见并清空，若 `initSentenceGame` / `initFillWordGame` 因素材不足提前返回，就会残留空壳。现改为先隐藏，由 `setQuestion()` 在题目渲染成功后才显示
- **🐛 未选年级 / 畸形存档解引用崩溃**：`journeyState()` 与 `renderLevelMap()` 在 `currentGrade` 为空时会读 `gradeData.units` 抛错。现补安全空状态兜底

## [1.5.1] - 2026-11-07

🐛 深度审查与故障注入专项修复（v1.5.0 封板后复审）

> 本版本**不含新玩法**，只修复审查中发现的稳定性、状态一致性与存档健壮性问题。`schemaVersion` 保持 **6**，旧存档无需迁移，v1.5.0 的全部功能与内容不变。

### 🐛 修复

- **🐛 致命 · 存档写入失败连锁失效**：录音落盘与「⬆️ 导入进度」都忽略 `saveUserData()` 返回值。存储配额满时，几百 KB 的 base64 仍留在内存中，之后每一次写存档都继续超限，星星 / 关卡 / 连续天数全部无法持久化；导入则会静默 `reload()` 让用户以为成功了。现写入失败即回滚内存状态，导入失败明确报错
- **🐛 句子小剧场连点重复发奖**：最后一题「完成闯关 ✓」连点会排出多个通关定时器，`totalGames`、星星、奖状各重复一次；非最后一题连点「下一句」会直接跳掉一题。`completeGame()` 加一次性守卫，按钮点击后立即禁用
- **🐛 切 Tab 后游戏卡死 / 奖状越页**：游戏题目推进依赖闭包内 `renderQuestion` 的短定时器，若在切页时统一清掉，孩子切回来会卡在已答对的那一题。改为保留推进定时器，由页面状态守卫抑制奖状与自动朗读；通关瞬间人在别的 Tab 时先记下，切回「🎮 游戏」再补发一次结算
- **🐛 直接点玩法 Tab 会朗读上一关单词**：`Play.showMode` 不经过 `App.showPage`，卡片 300ms / 句子 400ms 的自动朗读定时器未被清理，会在新玩法里读出旧单词。现统一作废 `speechToken` 并清掉这些定时器
- **🐛 跟读识别切页后偷偷发星**：`recognition.onend` 既未校验代次，又持有被 `innerHTML` 重建前的旧提示节点，切到首页后仍加分并弹徽章，用户却看不到评分。现代次校验 + 节点存活校验，切页时主动 `abort()` 关掉麦克风
- **🐛 剧情鼓励跨年级 / 非剧情模式误触发**：`Quest.activeUnit` 中途退出关卡后长期残留，之后从普通关卡地图完成同编号单元也会弹剧情提示。现回关卡地图、换年级、离开学习页即清空，`encourage()` 另加年级校验
- **🐛 畸形进度存档令成就页崩溃**：`normalizeUserData()` 只校验顶层类型，导入文件或篡改 localStorage 让数组混入 `null` / 对象时 `key.split('-')` 抛错、`missions` 畸形时任务 UI 显示 `NaN`、游戏任务被误标完成。现数组元素统一过滤为字符串、计数归一为有限数字、`reviewSchedule` 与 `dubs` 条目做结构校验
- **🐛 跨天「今日复习」按钮保持禁用**：日切检查只刷新连续天数与每日任务，未刷新复习卡计数；昨天为 0 时今天按钮仍禁用，孩子进不去复习。现跨天后同步刷新
- **🐛 宠物升级语音打断单词发音**：`addXp()` 的 `SpeechHelper.speak('Wow!...')` 会先 `cancel()`，掐掉孩子刚点的单词 / 句子示范朗读。改为只保留轻提示 + 纸屑（与贴纸解锁一致）
- **🐛 删除配音后 Tab 计数不刷新**：`renderDubList` 的删除回调只重绘列表，顶部「🎬 配音 N」停在旧数字。现改走 `App.updateWordList()` 同步刷新
- **🐛 连连看 / 记忆翻牌出现两张相同图片**：词库存在 28 组重复 Emoji（如 `hello` / `goodbye` 同为 👋），`getGameWords()` 只按单词去重，配对时孩子无法区分。现按 Emoji 去重，5 年级 × 6 Level × 8 词全部验证无重复且数量充足
- **🐛 Combo 连击跨 Tab 丢失、跨玩法残留**：`showPage()` 直接 `Combo.reset()` 清掉进行中的连击（游戏 DOM 并未重建），而 `Play.showMode()` 又完全不重置。现切 Tab 只隐藏徽标保留计数，切趣味乐园玩法才重置
- **🐛 重复完成玩法无限刷经验 / 存档膨胀**：`Play.reward()` 的 `addXp()` 写在「首次完成」判定之外；每日盲听还按日期往 `playDone` 塞 key。现宠物经验只在首次完成给，盲听由 `listenDate` 独立判定每日发星，`playDone` 不再按天增长
- **🐛 录音授权期间切换卡片串状态**：`getUserMedia()` 异步完成后会把新卡片的按钮改成「⏹️」并重绘新卡片，让人以为录的是 B 实际录的是 A。现用 `currentWordKey()` 确认卡片未变
- **🐛 底部提示堆叠依赖 `offsetHeight`**：首帧尚未布局时为 0，多个提示会叠在一起；现给兜底高度
- **🐛 离开盲听后旧语音回调重新挂定时器**：`Play.stopAll()` 现调用 `cancelBlind()` 连代次一起作废，避免切页后残留朗读
