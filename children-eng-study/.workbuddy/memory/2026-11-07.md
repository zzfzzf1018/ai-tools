## 封板与发布（用户要求 review → 测试 → 修复 → 提交推送打 TAG）

- 审查发现并修复 7 类问题：
  1. `PlayLab.today/addDays` 用 `toISOString()`（UTC），UTC+8 凌晨会把今天算成前一天 → 新增 `formatDate` 用本地年月日字段。
  2. 复习首次答对排期 off-by-one（`REVIEW_INTERVALS[step]` 跳过 1 天）→ 改为 `[step-1]`；毕业条件 `>= length` 导致 15 天间隔从未生效 → 改为 `> length`，完整走完 1/2/4/7/15 五轮后毕业。
  3. `followReadText` 的 `onerror` 后 `onend` 仍会发星 → 加 `hadError` 短路；切离学习页后 1800ms 定时器仍启动麦克风 → 加 `followReadToken` 代次（showPage 非 learn 时递增）。
  4. `saveUserData` 不返回状态，配音遇 QuotaExceeded 时界面显示成功但重载丢失 → 返回 boolean，saveDub 失败回滚数组。
  5. Phonics `/k/` 干扰项含同样发 /k/ 的 `k`、`/s/` 含可发 /s/ 的 `c` → 改为 c/s/t 与 s/z/t。
  6. 儿歌固定 1600ms 间隔，长句会被下一行 cancel → 按 `Math.max(1500, len*75)` 自适应；清理未使用字段 `storyPicked`。
