# 使用手册

面向使用者的完整操作说明。每个界面元素的作用、常见操作路径、以及遇到问题时的处理方式。

---

## 1. 首次打开

首次启动会看到今日页，四个数字都是 0，提示「今天没有到期复习」。

默认配置：

| 项 | 默认值 |
| --- | --- |
| 每日新词 | 20 |
| 每日复习上限 | 200 |
| 每轮卡片 | 20 |
| 学习范围 | 全部四个频段 |
| 新词顺序 | 按词频 |
| 题型 | 混合 |
| 主题 | 深色 |

如果你只想先试试，直接点「开始学习」。如果想先调整计划，去「设置」。

---

## 2. 今日页

### 顶部卡片

一句话告诉你今天最该做什么，以及一个进度条。

进度条的口径是：今日已完成 ÷ (今日已完成 + 今天剩余任务)。剩余任务 = 到期复习数 + 今日剩余新词额度。

所以随着学习推进，分母会缩小，进度条会加速——这是刻意的，能给人正反馈。

### 四个统计块

| 块 | 含义 | 附注 |
| --- | --- | --- |
| 待复习 | 现在到期、还没复习的词数 | 附注显示其中多少处于「学习中」 |
| 今日新词 | 今日已学新词 / 每日上限 | 附注显示剩余额度 |
| 已掌握 | 手动标记「不需要背了」的词数 | 附注显示占全库比例 |
| 连续打卡 | 连续有学习记录的天数 | 附注显示累计学习天数 |

「连续打卡」的计算规则：今天有记录就从今天往前数；今天还没开始就从昨天往前数。所以早上打开看到「连续 5 天」不会因为今天还没学而变成 0。

### 未来 7 天到期预测

柱状图展示未来一周每天有多少词到期。用途：

- 如果明天有 200 个词到期，说明今天的复习积压了，该处理一下
- 如果未来几天都是 0，说明该多学点新词了

## 3. 学习页

### 卡片上的标签

左上角的标签告诉你这张卡的来历：

| 标签 | 含义 |
| --- | --- |
| 新词 | 从未学过 |
| 学习中 | 正处于 1 分钟 / 10 分钟的短间隔阶段 |
| 复习 | 已进入长期记忆阶段 |
| 重点 | 你标记过的重点词 |
| 第 N 次 | 这张卡在本轮会话中第几次出现（答错重排时出现） |
| 核心 / 常用 / 进阶 / 拓展 | 所属词频段 |

### 三种题型

**看英文选中文（en2zh）**

卡面显示英文单词 + 音标 + 发音按钮，四个选项是中文释义。

**看中文选英文（zh2en）**

卡面显示中文释义，四个选项是英文单词 + 音标。

干扰项从**同频段**随机抽取，且保证释义互不相同，避免出现两个选项都对的情况。

**拼写（spell）**

卡面显示中文释义 + 音标，下方是输入框，按 `Enter` 提交。

只有满足以下条件的词会出拼写题：长度 3–24、纯英文字母（可含连字符与撇号）、不是功能词。

**功能词只考英译中**：冠词（art.）、介词（prep.）、连词（conj.）、代词（pron.）、助动词（aux.）、数词（num.）这类词的中文解释是一长串语法说明，作为题干既啰嗦又无法区分，所以系统会自动把它们降级为「看英文选中文」。

### 作答与自评

选择题点击选项后、拼写题提交后，卡片会翻面：

1. 显示完整词条（单词 / 音标 / 释义）
2. 答错时显示「你选了：xxx」
3. 下方出现四个评分按钮，每个按钮上标着下次出现的间隔

**自评是唯一影响算法的输入**，选择题的对错只用于展示。这意味着：

- 蒙对了但心里没底 → 请选「有点模糊」
- 一眼认出 → 请选「很简单」

### 其他操作

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 直接看答案 | 底部 | 不猜了，直接翻面看答案（此时自评仍然必填） |
| 跳过这个词 | 底部 | 不记录评分，把卡片移到队尾 |
| 标记重点 | 翻面后 | 让这个词在未来的复习队列中优先出现 |
| 已掌握，不再出现 | 翻面后 | 立即从队列移除并标记掌握 |
| 结束本轮 | 右上角 | 提前结束，剩余卡片不记录 |

### 结束页

显示本轮数据：正确率、新学数、复习数、忘记次数、总用时。可以「再来一轮」（重新构建队列）、回到今日、或查看统计。

## 4. 词库页

### 搜索

输入框支持：

- 英文精确匹配（`abandon`）→ 排最前
- 英文前缀（`aban`）
- 英文包含（`band`）
- 中文包含（`放弃`）

搜索范围是全库 8000 词，结果最多 8000 条，按「精确 > 前缀 > 包含 > 释义」排序。

### 筛选

两行筛选器：

**状态**：全部 / 未学习 / 学习中 / 复习中 / 已掌握 / 重点

**频段**：全部频段 / 核心 1-1000 / 常用 1001-3000 / 进阶 3001-5500 / 拓展 5501-8000

两个筛选条件可以叠加。点「重置条件」清空全部筛选与搜索。

### 列表操作

每行右侧三个按钮：

| 图标 | 作用 | 可撤销 |
| --- | --- | --- |
| 🔊 喇叭 | 朗读单词 | — |
| ⭐ 星标 | 标记 / 取消重点 | 是，再点一次 |
| ✓ 对勾 | 标记 / 取消「已掌握」 | 是，再点一次 |

标记「已掌握」后整行会变淡，但不会消失（仍然可以在「已掌握」筛选里找到并撤销）。

### 分页

每页 50 条，底部显示页码与翻页按钮。搜索或筛选变化时会自动回到第 1 页。

## 5. 统计页

### 顶部四块

| 块 | 口径 |
| --- | --- |
| 已学词数 | 状态非「新词」且非空的词数（含已掌握） |
| 已掌握 | 手动标记为 MASTERED 的词数 |
| 成熟词 | 复习间隔 ≥ 21 天的词数 |
| 累计正确率 | 全部作答中自评为「记得」或「很简单」的比例 |

### 今日

今日新学、复习、作答次数、今日正确率、专注时长。

专注时长是每张卡从展示到提交的时间之和，单卡超过 5 分钟按 5 分钟计（避免离开页面导致数据失真）。

### 热力图

最近 13 周、每周 7 天的活跃度，颜色越深表示当天学的卡片越多。今天的格子有描边。

### 最近 14 天

堆叠柱状图：底部蓝色是新学，顶部绿色是复习。鼠标悬停可以看到当天的具体数字。

### 频段掌握情况

每个频段的总词数、已学数、已掌握数，用进度条表示。深绿色是已掌握，蓝色是已学未掌握。

### 记忆强度分布

把已学的词按记忆强度分成 5 档（0–20%、20–40%……），显示每档有多少词。理想状态是右多左少。

## 6. 设置页

### 学习计划

| 设置 | 范围 | 说明 |
| --- | --- | --- |
| 每日新词上限 | 0–500 | 设置为 0 表示今天不学新词，只复习 |
| 每日复习上限 | 20–2000 | 到期词超过上限会顺延到明天 |
| 每轮卡片数 | 5–200 | 单次会话的最大卡片数 |

数值可以直接在输入框里改，也可以点 `−` / `+` 按钮。输入框失焦时不会强制回写，但实际生效值会被夹到合法范围内。

### 学习内容

| 设置 | 说明 |
| --- | --- |
| 参与的频段 | 至少保留一个。取消全部会自动恢复为全部 |
| 新词出现顺序 | 按词频 / 乱序 / 新词优先 |
| 题型 | 混合 / 只做选择题 / 只做拼写题 |
| 显示音标 | 关闭后卡片与词库都不显示音标 |
| 自动朗读 | 翻面时自动朗读单词 |

### 外观

深色 / 浅色主题，立即生效并保存。

### 数据

| 操作 | 说明 |
| --- | --- |
| 导出 | 下载 `wordmemory-backup-YYYY-MM-DD.json`，包含全部进度、设置、统计 |
| 导入 | 选择 JSON 文件，**覆盖**当前进度（导入前建议先导出） |
| 清空进度 | 删除全部卡片状态与统计，保留设置。需要二次确认 |

### 关于

显示应用版本、词库词条数、词库版本、数据来源、数据指纹，以及快捷键提示。

## 7. 快捷键

| 按键 | 生效时机 | 作用 |
| --- | --- | --- |
| `空格` | 作答阶段 | 显示答案 |
| `Enter` | 输入框中 | 提交拼写 |
| `A` `B` `C` `D` | 选择题 | 选择对应选项 |
| `1` `2` `3` `4` | 看答案后 | 评分 |
| `空格` | 看答案后 | 快速选「记得」 |
| `S` | 任意时刻 | 朗读当前单词 |
| `Esc` | 学习页 | 结束本轮 |

在输入框内输入时，除 `Esc` 外的快捷键不会触发。

## 9. 数据迁移

### 换设备

1. 旧设备：设置 → 数据 → 导出，得到 JSON 文件
2. 传输文件（微信 / 邮件 / U 盘都可以）
3. 新设备：设置 → 数据 → 导入，选择该文件

导入会**完全覆盖**当前进度，包括统计。

### 备份建议

- 每周导出一次
- 大版本更新前导出一次
- 清理浏览器数据前导出一次

### 数据丢失的常见原因

| 原因 | 是否可恢复 |
| --- | --- |
| 清除浏览器「Cookie 及其他网站数据」 | 否 |
| 使用无痕模式 | 否（关闭窗口即丢） |
| 换了浏览器或设备 | 否，需要手动导入 |
| 单文件版移动到不同路径（部分浏览器按路径隔离） | 可能读不到旧数据 |
| 私密浏览 / 禁用 localStorage | 否，应用会提示降级为内存模式 |

## 10. 常见问题排查

**卡片一直不出现**

- 检查「设置 → 参与的频段」是否排除了该词的频段
- 检查该词是否被标记为「已掌握」
- 检查是否已达当日新词/复习上限

**复习量突然变得很大**

- 这是中断几天后的正常现象
- 把「每日复习上限」调到 50，分几天消化
- 不要一次清空——那会导致后面几天全在复习，没法学新词

**发音没声音**

- 浏览器需要支持 `speechSynthesis`（Chrome / Edge / Safari 均支持）
- 部分系统需要先下载英文语音包
- 有些浏览器在无用户交互时不播放语音，点一下页面再试

**导入后数据没变化**

- 确认导入的文件是本应用导出的 JSON（含 `words` 字段）
- 导入成功会提示「已导入 N 条学习记录」

**词库搜索不到某个词**

- 词库只收录 8000 个高频词，非常用词可能不在其中
- 换个更短的关键词试试
