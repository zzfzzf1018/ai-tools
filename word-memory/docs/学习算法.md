# 学习算法说明

本文说明 WordMemory 的间隔重复（Spaced Repetition）实现，包括状态机、计算公式、调度策略与参数取舍。

对应代码：`src/core/srs.js`、`src/core/scheduler.js`、`src/core/session.js`。

---

## 1. 为什么是间隔重复

1885 年，艾宾浩斯用无意义音节做实验，画出了人类第一条遗忘曲线：新学的信息在最初 20 分钟遗忘约 42%，一天后遗忘约 66%，一个月后遗忘约 79%，之后趋于平缓。

关键结论是：**遗忘速度随每次成功回忆而变慢**。

如果每次都在「即将忘记」的时刻复习，就能用最少的复习次数把记忆维持到最长。间隔重复就是把这个规律工程化：

```
复习次数      1      2      3      4      5      6
保持时长     1天    3天    7天    16天   35天   80天
```

传统背单词方式（每天把整张表过一遍）的问题在于：已经记住的词被反复复习，浪费了大量时间；而真正快忘的词却没有得到额外关注。

## 2. 状态机

每个词在任一时刻处于四种状态之一：

```
              ┌─────────────────────────────────────────┐
              │                                         │
   [NEW]  ──► [LEARNING] ──► [REVIEW] ──► [MASTERED]    │
   新词         学习中        复习中       已掌握(手动)   │
     ▲            │  ▲           │                     │
     │            │  └───────────┘ 答错(lapse)          │
     │            │                                  │
     └────────────┴──────── 取消「已掌握」──────────────┘
```

| 状态 | 值 | 含义 | 是否进队列 |
| --- | --- | --- | --- |
| NEW | 0 | 从未学过 | 是（作为新词） |
| LEARNING | 1 | 短期学习中，间隔以分钟计 | 到期后是 |
| REVIEW | 2 | 长期复习中，间隔以天计 | 到期后是 |
| MASTERED | 3 | 用户手动标记「不需要再背」 | 否 |

`MASTERED` 是唯一由用户直接控制的终态，算法不会自动把词标成这个状态——是否「不需要背了」应该由人判断。

---

## 3. 状态字段

```js
{
  s:     0,      // 状态 0-3
  ef:    2.5,    // 难度因子 Ease Factor，决定间隔增长倍率
  iv:    0,      // 当前间隔（天），仅 REVIEW 阶段有意义
  reps:  0,      // 进入复习阶段后的成功复习次数
  due:   0,      // 下次到期时间戳（毫秒）
  last:  0,      // 上次作答时间戳
  lapse: 0,      // 遗忘次数（在复习阶段答「忘记了」的次数）
  star:  0,      // 重点标记 0/1
  seen:  0,      // 累计作答次数
  ok:    0,      // 累计答对次数（自评为「记得」或「很简单」）
  step:  0,      // 学习步骤索引 0-1
}
```

字段全部使用短名，是为了压缩 localStorage 体积——8000 个词全学完时，字段名少一个字符就能省下 8 KB。

---

## 4. 参数

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `LEARNING_STEPS` | `[1, 10]` 分钟 | 新词的两个学习步骤 |
| `EF_DEFAULT` | `2.5` | 初始难度因子 |
| `EF_MIN` / `EF_MAX` | `1.3` / `3.0` | 难度因子上下限 |
| `GRADUATING_INTERVAL` | `1` 天 | 正常毕业的首次间隔 |
| `EASY_INTERVAL` | `4` 天 | 直接「很简单」毕业的首次间隔 |
| `MAX_INTERVAL` | `365` 天 | 间隔上限 |
| `MATURE_INTERVAL` | `21` 天 | 统计意义上的「成熟词」 |
| `IN_SESSION_REQUEUE_MS` | `3` 分钟 | 到期时间小于该值的卡片本轮重排 |
| `MAX_APPEARANCE` | `3` | 同一张卡单轮最多出现次数 |

## 5. 计算规则

评分（grade）取值为 0–3：

| grade | 名称 | 界面文案 | 含义 |
| --- | --- | --- | --- |
| 0 | AGAIN | 忘记了 | 完全想不起来 |
| 1 | HARD | 有点模糊 | 想起来了但很吃力 |
| 2 | GOOD | 记得 | 正常回忆 |
| 3 | EASY | 很简单 | 秒懂 |

### 5.1 学习阶段（s = NEW 或 LEARNING）

```
AGAIN:  step = 0,  due = now + 1 分钟
HARD:   step 不变, due = now + min(step 间隔 × 1.5, ...) 
GOOD:   step + 1
        ├─ 未超过最后一步 → due = now + LEARNING_STEPS[step]
        └─ 已到最后一步   → 毕业：s = REVIEW, iv = 1, due = now + 1 天
EASY:   直接毕业：s = REVIEW, ef + 0.15, iv = 4, due = now + 4 天
```

为什么「很简单」直接给 4 天？如果用户对一个词毫无迟疑，说明它已经具备长期记忆的基础，再让它 1 分钟后出现只是浪费时间。经典 Anki 的默认 easy interval 同样是 4 天。

### 5.2 复习阶段（s = REVIEW）

设当前间隔为 `iv`，难度因子为 `ef`：

```
AGAIN:  lapse + 1
        s = LEARNING, step = 0, iv = 0
        ef = clamp(ef - 0.2, 1.3, 3.0)
        due = now + 1 分钟

HARD:   ef = clamp(ef - 0.15, 1.3, 3.0)
        iv = max(1, round(iv × 1.2))

GOOD:   iv = max(1, round(iv × ef))

EASY:   ef = clamp(ef + 0.15, 1.3, 3.0)
        base = max(1, round(iv × ef))
        iv = max(base + 1, round(base × 1.3))
        
统一：  iv = min(iv, 365)
        reps + 1
        due = now + iv 天
```

`EASY` 那一行多出来的 `max(base + 1, ...)` 是为了保证「很简单」的间隔**严格大于**「记得」。否则当 `iv = 1` 时，`round(1 × 2.5) = 3`、`round(1 × 2.65 × 1.3) = 3`，两个按钮会给出完全一样的结果，用户会觉得按钮坏了。

### 5.3 手动标记

```
标记「已掌握」：  s = MASTERED, iv = 0, due = 0, step = 0
取消「已掌握」：  reps > 0 ? s = REVIEW（due = 立即） : s = NEW
```

取消时会根据历史决定回到哪个阶段，已经学过很多次的词不会被打回新词重头再来。

## 6. 推演示例

一个词当前 `iv = 10`，`ef = 2.5`，状态为 REVIEW。

| 用户选择 | ef 变化 | iv 计算 | 结果 |
| --- | --- | --- | --- |
| 忘记了 | 2.5 → 2.3 | 重置 | 1 分钟后重新学，`lapse = 1` |
| 有点模糊 | 2.5 → 2.35 | `round(10 × 1.2) = 12` | 12 天后 |
| 记得 | 2.5 | `round(10 × 2.5) = 25` | 25 天后 |
| 很简单 | 2.5 → 2.65 | `base = 27`，`max(28, 35)` | 35 天后 |

连续选「记得」的间隔增长：

| 次数 | iv | 累计天数 |
| --- | --- | --- |
| 1 | 1 | 1 |
| 2 | 3 | 4 |
| 3 | 8 | 12 |
| 4 | 20 | 32 |
| 5 | 50 | 82 |
| 6 | 125 | 207 |
| 7 | 313 | 520 |
| 8 | 365（封顶） | 885 |

可以看到，一个词只需要 6–8 次正确复习、总耗时约 2 年，就能获得接近永久的记忆。这就是间隔重复的效率来源。

## 7. 队列调度

每天打开应用时，`buildQueue()` 会算出本次会话要学的卡片（`src/core/scheduler.js`）。

### 7.1 收集候选

遍历词库全部 8000 条：

```
对每个词：
  ├─ 不在用户选择的频段内        → 跳过
  ├─ 无记录 或 状态 = NEW        → 进入「新词池」
  ├─ 状态 = MASTERED             → 跳过
  └─ 状态 = LEARNING / REVIEW 且 due ≤ now → 进入「到期池」
```

### 7.2 排序

**到期池**按三级排序：

1. 重点标记（`star`）优先
2. 到期时间更早的优先（积压更久的先处理）
3. 遗忘次数更多的优先

**新词池**按设置的顺序：

- `frequency`（默认）：词频由高到低，即索引升序
- `random`：以日期为种子的洗牌，保证同一天内刷新顺序稳定
- `new-first`：先排新词再排复习（会话组织阶段生效）

重点标记的新词会排在新词池最前。

### 7.3 限额

```
可用新词数 = max(0, 每日新词上限 - 今日已学新词)
可用复习数 = max(0, 每日复习上限 - 今日已复习数)
```

限额按「今日已完成量」扣减，而不是简单地按会话计数，所以一天内多次打开会话也不会超量。

### 7.4 交错

复习和新词按比例均匀混合，而不是「先把复习做完再看新词」：

```
interleave([r1..r9], [f1]) = [r1, r2, r3, r4, r5, r6, r7, r8, r9, f1]
interleave([r1..r5], [f1..f5]) = [r1, f1, r2, f2, r3, f3, ...]
```

实现上用整数运算 `floor((k+1) × b.length / total)` 计算目标插入量，避免浮点误差导致新词全部挤在开头。

最后的队列会按 `sessionSize`（默认 20）截断，学完可以「再来一轮」。

## 8. 会话内重排

一次学习会话中，某些卡片会再次出现（`src/core/session.js`）：

```
提交评分后：
  若 新状态仍为 LEARNING 或 REVIEW
     且 (due - now) ∈ [0, 3 分钟]
     且 该卡本轮出现次数 < 3
  → 重新插入队列第 3 位（`min(remaining, 3)`）
```

只有「忘记了」会触发（间隔 1 分钟）。「有点模糊」在学习阶段是 1.5 分钟，同样会触发一次；「记得」是 10 分钟，不会在本轮重排。

为什么不把 10 分钟的卡也重排？因为一次会话通常只有几分钟，强迫用户等 10 分钟不符合实际使用场景；让它留到下一个会话更自然。

**防死循环**：同一张卡最多出现 3 次，第 3 次之后无论评什么分都直接离开队列。

## 9. 与经典 SM-2 的差异

| 项 | 经典 SM-2 | 本项目 | 原因 |
| --- | --- | --- | --- |
| 评分档位 | 0–5 六档 | 0–3 四档 | 用户难以区分 6 档，四档足够且对应明确 |
| 学习步骤 | 无 | 1 分钟 / 10 分钟 | 短间隔巩固对中文母语者学英文更有效 |
| 间隔单位 | 天 | 分钟（学习阶段）+ 天（复习阶段） | 学习阶段用天太粗 |
| 间隔上限 | 无 | 365 天 | 长期不用会导致「到期洪峰」 |
| 会话内重排 | 无 | 有（最多 3 次） | 提高当日留存 |
| 复吸惩罚 | Q < 3 重置 | AGAIN 重置 + EF −0.2 | 与四档评分对应 |

## 10. 容错

`normalizeState()` 会对任何外部输入做修补，保证界面不会因为脏数据崩溃：

| 异常输入 | 处理 |
| --- | --- |
| `s` 不在 0–3 | 视为 NEW |
| `ef` 非数字或越界 | 回到 2.5，或夹到 [1.3, 3.0] |
| `iv` 超过 365 | 夹到 365 |
| `due` 为 null / 负数 | 置 0 |
| `star` 为任意真值 | 归一为 1 |
| 记录缺失 | 返回全新默认状态 |

导入备份时同样走这条路径，所以旧版本存档、手工编辑过的 JSON 都不会导致白屏。

## 11. 记忆强度估算

统计页的「记忆强度」是一个 0–1 的启发式指标，用于直观展示掌握程度：

```
间隔分   = log2(1 + iv) / log2(1 + 21)          // 21 天视为满分参照
遗忘惩罚 = 1 / (1 + lapse × 0.35)
正确率   = ok / seen
强度     = clamp(间隔分 × 0.6 × 遗忘惩罚 + 正确率 × 0.4, 0, 1)
```

- 已掌握 → 固定 1.0
- 新词 → 0
- 间隔越长、忘得越少、正确率越高 → 越接近 1

它不参与调度决策，只用于展示。
