# 更新日志

本文件记录心晴岛（Sunny Isles）的版本变更。版本号遵循语义化版本（SemVer），并与 git tag `children-social-emotional-learning-vX.Y.Z` 对应。

## [1.0.5] - 收尾：计时器、故事结算与记录展示

- **资源**：彩带与「冷静工具箱」练习计时的定时器改为统一登记，弹窗关闭或换页时立即清掉。此前关掉练习弹窗后计时器最多还会空转 1 秒，换页后残留的彩带也会继续飘 1.4 秒。
- **故事关**：选项的能力点改为点「继续故事」时才写入，只点开看看又离开不再计数；同时只在第一次走完该关卡时累加，重玩可以继续探索别的分支，但不会把同一份练习反复记成新的能力点。
- **签到**：第 4 步新增可选的「给自己留一句话」输入（最多 120 字），写下的内容会跟着这一次签到一起保存。
- **记录展示**：心情花园的花朵详情现在会显示当天写下的那句话和试过的小方法；档案页显示每个档案「加入日期 / 最近一次玩」；家长面板新增「最近的签到」表（日期、心情、强度、写下的话）与最近一次记录时间。
- **存档**：超出展示上限的签到（400 条）与心情花（365 朵）不再直接丢弃，而是自动移入归档（每档最多 2000 条签到 / 1000 朵花），随导出备份一起保存、导入时一并还原；「清空当前档案进度」会连归档一起清掉，删档也不会留下孤儿数据。
- **测试**：新增计时器清理、故事技能点结算时机、签到备注写入与展示、归档往返与清空等回归用例。

## [1.0.4] - 发布后复查修复

- **安全**：本地预览服务 `desktop/serve.mjs` 原先监听 `0.0.0.0`，局域网内其他设备可读取整个项目目录；现改为只绑定 `127.0.0.1`。
- **存档**：坏档备份改用固定 key，并在备份成功后立即把可用新档写回主 KEY；此前每次启动都会新增一个 `-corrupt-<时间戳>` 备份且永不清理，localStorage 只增不减。
- **存档**：用户/备份可控的字符串字段统一限长（昵称 12、原因/备注 500、其他短字段 40–60 字），拒绝超过 5 MB 的备份文件，避免把 localStorage 配额撑爆后静默降级。
- **存档**：心情花保留上限由 120 提高到 365（约一年），花园在达到上限时明确提示「最近 N 朵、更早的会自动收起来、可导出备份」，不再把截断后的数量写成「一共」。
- **无障碍**：弹窗打开时把键盘焦点移入弹窗，Tab 在弹窗内循环，关闭后把焦点还给原元素；此前焦点一直留在背景页面。
- **文案**：删除「连续签到还有小惊喜」（并无对应奖励逻辑）；练习弹窗改为「完整做完一次才会记下练习次数」，与实际计次行为一致。
- **一致性**：首页快捷卡与地图标题的小岛数、玩法说明页以外的「5 个小方法」改为从课程数据实时读取。
- **打包**：`build.files` 排除仅供开发用的 `desktop/serve.mjs`，便携版不再附带本地服务器。
- **文档**：修正 README 中五座小岛的名称、签到四步流程、贴纸与家长面板功能描述，补齐 `scripts/release-notes.cjs`，修掉两处笔误。
- **测试**：`verify.mjs` 增加「每关只拿最低星数」的解锁可达性模拟与预览服务绑定地址检查；`smoke.mjs` 增加坏档备份、超长字段截断、弹窗焦点、花园上限文案、数量动态一致等回归用例。

## [1.0.3] - 封板前质量修复

- 修复呼吸练习「先停一下」后无法重新开始的问题（开始按钮一直禁用、计时器无法复位）。
- 修复未解锁岛屿/关卡可通过直接修改地址栏 hash 绕过的问题；「下一关」只在下一关确实解锁时出现。
- 修复导入空 JSON 或非法备份会静默清空现有存档的问题：现在会拒绝并给出提示，坏档另存备份而不覆盖。
- 修复关卡完成按钮连点会重复累加「能力练习次数」的问题。
- 修复切换签到情绪后，上一种情绪选择的原因仍被写入记录的问题。
- 修复关卡页顶部星星恒显示 3 颗、首页关卡数写成 18（实际 19）等展示错误。
- 修复分类玩法中点击已放入篮子的卡片会弹出「先选一张卡片」错误提示的问题；排序成功后不再允许打乱已完成的答案。
- 修复心情花园同一天同情绪多次签到时，详情显示最早一条而非最新一条的问题。
- 存档读取与导入全面加固：清洗非法字段、限制记录上限、保护声音/动效设置不被「清空进度」重置；同一台电脑最多 12 个小玩家档案。
- 修复过关彩带被完成弹窗遮住的问题（彩带层级提到弹窗之上、提示之下）。
- 「玩法说明」页的小岛数、关卡数、游戏玩法数、冷静方法数改为从数据实时读取，不再写死。
- 桌面版增加单实例锁，避免便携版重复启动时两个窗口同时写同一份存档。
- 测试增强：冒烟测试现覆盖解锁链路、存档导入、连点结算、呼吸重开、家长门、档案增删与 12 个档案上限。

## [1.0.2] - 新增应用内「玩法说明」

- 首页新增「ℹ️ 玩法说明」入口按钮。
- 本次发布起，GitHub Release 说明自动包含本段 `CHANGELOG.md` 内容（首次以完整改动内容发布，验证发布说明自动化机制）。
- 应用其余功能与 1.0.1 一致。

## [1.0.1] - 首次自动化发布修复

- 修复 GitHub Actions 发布流水线：将 `npm ci` 移至 `Plan release` 步骤之前，解决 `scripts/release.cjs` 在 `plan` 阶段 `require('semver')` 找不到模块（MODULE_NOT_FOUND）导致流水线中断的问题。
- 将 `npm ci` 改为 `npm install`，规避 electron-builder 平台专属可选依赖（如 macOS 的 dmg-license）导致的跨平台锁严格校验失败（EUSAGE）。
- 在 `npm install` 后增加 `git checkout -- package-lock.json`，还原被 npm 按平台重写的 lock 文件，满足发布流水线对干净工作树的要求。
- 将发布工作流自身加入 `paths` 过滤，确保仅修改工作流时也能自动触发 CI。
- 每次发布自动将本版本在 `CHANGELOG.md` 中的段落作为 GitHub Release 说明（release notes），确保发布包含改动内容；同时保留应用使用说明与离线/校验提示。
- 此为首次经 CI 成功打 tag 并发布 GitHub Release 的版本（应用功能与 1.0.0 一致）。

## [1.0.0] - 初版

- 5 座 SEL 小岛、19 个互动关卡（7 种题型）。
- 10 种情绪脸谱、每日 4 步情绪签到、心情日历。
- 5 个"策略肌肉"（觉察 / 呼吸 / 应对 / 拉开距离 / 表达）。
- 情绪花园 + 12 枚奖励贴纸 + 多档案。
- 家长面板（算术家长门、数据雷达、打卡日历、关卡进度、JSON 备份导入导出）。
- Web 版（双击 `index.html`，`file://` 离线运行）与 Windows 桌面便携版（Electron 单文件 exe）。
- 全离线：Web Audio 合成音效、浏览器 TTS 中文语音、内联 SVG 美术，零外部资源。
- 静态校验（`tools/verify.mjs`）与 jsdom 运行时冒烟测试（`tools/smoke.mjs`）。
- GitVersion 版本管理与 GitHub Actions 自动构建/发布。
