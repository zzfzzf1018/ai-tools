# 更新日志

本文件记录心晴岛（Sunny Isles）的版本变更。版本号遵循语义化版本（SemVer），并与 git tag `children-social-emotional-learning-vX.Y.Z` 对应。

## [1.1.2] - 深度测试修复：家长护栏、日期清洗与归档安全

- **家长护栏（严重）**：修复「清空当前档案进度」会连家长的**每日时长上限与睡前锁**一起清掉的问题。此前家长一清空进度，孩子的使用限制就静默失效（`screenLimit` / `bedtimeOn` / 起止时间全部丢失）；现在这两类设置跨「清空进度」存活，只清星星、关卡、签到、贴纸等进度数据。
- **存档（中）**：修复导入备份里**语义非法的日期**（如 `2026-99-99`、`2026-02-30`）能通过格式校验进入存档的问题——此前这类日期会在心情花园里直接显示成「99月99日」。现在日期除格式外还做「解析再回写」比对，非法日期整条丢弃；签到、心情花、使用时长日期与档案的创建/最近访问日期全部适用。
- **存档安全（中）**：修复导入备份的 `archive.__proto__` / `constructor` 键会把归档对象的原型改成备份可控对象的原型污染问题（`JSON.parse` 把 `__proto__` 做成自有键，但普通对象的 `[key]` 赋值会触发原型 setter）。归档键现在与档案 id 走同一套安全白名单，导入后归档对象原型保持干净。
- **清理**：移除 `screens.js` 中未使用的死变量 `C`（与 `UI` 重复引用同一模块）。
- **测试**：`smoke` 新增第 27 组回归用例，把本轮手工排查全部固化为自动化——「清空进度」保留家长护栏、非法日期拦截、归档键清洗（含原型污染变异验证）、**睡前锁全流程**（此前只测了时长上限锁：到点盖休息卡、挡住冷静角、家长门解锁后当天不再打扰）、签到强度滑块端到端落库、`weekStart` / `addDays` / `dayDiff` 与睡前锁跨午夜判断的单元断言。

## [1.1.1] - 修复 Web 发布包缺失 PWA 资源

- **发布包（严重）**：`1.1.0` 的 `SunnyIsles-SEL-1.1.0-web.zip` 只打包了 `index.html`、`src`、`desktop` 与文档，漏掉了 `manifest.webmanifest`、`sw.js` 与 `icons/`。用户下载后能正常打开网页，但**装不到桌面、也离线不了**。现在 Web 包会一并带上 PWA 三件套，并在打包后重新打开 zip 逐项核对，缺文件直接让发布失败。
- **预览服务**：`desktop/serve.mjs` 为 `.webmanifest` 补上 `application/manifest+json`（此前落到 `application/octet-stream`，Chrome 不认安装清单）；入口 HTML、脚本与清单改为 `no-store`，避免换了版本浏览器还在用旧的 `sw.js`。
- **测试**：`verify` 新增两项契约检查——`release.cjs` 的 Web 打包清单必须含 PWA 三件套、预览服务必须给 `.webmanifest` 正确 MIME，防止同类漏打包再次发生。

## [1.1.0] - 情绪急救、家长洞察与离线安装

- **情绪急救悬浮按钮**：所有儿童页面右下角新增「冷静 60 秒」按钮，任何页面一键打开 60 秒呼吸（4-2-6 节奏），只盖一层弹窗、不换路由、不重绘当前关卡；关掉就回到刚才那一题，练习完成计入冷静工具箱次数。
- **情绪趋势**：家长面板新增 14 / 30 天情绪强度折线图，按天计算平均值；没有签到的日子留空断线，不会被误画成 0。切换区间即时重绘。
- **策略有效性**：统计「用了某个方法后，一周内下一次签到的强度变化」，展示样本数、平均变化与下降比例；样本少于 3 次的行以灰字标注「先当作参考」，并明确说明相关不等于因果。
- **本周建议 3 关**：按五座岛的练习次数从少到多，自动挑出还没做且已解锁的关卡（全做完则建议重玩星数最少的一关），家长不用再自己对照雷达图。
- **使用时长与睡前锁**：家长可设置每日上限（15–90 分钟）与睡前时段（24 小时制下拉，避免英文系统显示 AM/PM）。到点只盖一层休息提醒，不删记录；「请大人来解锁」需要再过一次家长门，解锁后当天不再打扰。
- **家长 PIN**：可设置 4 位 PIN 代替算术题。存档只保存加盐哈希、不存明文；连续输错 5 次锁定 1 分钟；忘记 PIN 只能清除浏览器数据，界面已如实提示。
- **成长周报 / 心情天气卡**：新增 `#/report` 页面，汇总本周记录天数、平均强度、开出的花、用过的方法与 7 天天气条，附给大人的对话建议；支持打印或另存为 PDF，打印样式只输出卡片本身。
- **故事分支探索度**：走到结局时显示「已发现 x / y 个结局」与「还有 N 条路没走过」，鼓励孩子换一个做法再走一遍；探索进度随存档保存。
- **PWA 离线安装**：新增 `manifest.webmanifest`、Service Worker 与 192/512 图标。平板或电脑用浏览器打开后可「安装到桌面」，断网也能启动；Electron 桌面版走 `file://`，自动跳过注册，行为不变。
- **视觉回归**：新增 `npm run visual` / `npm run visual:update`，用 Electron 冻结时间在 2026-01-15，按桌面 1280px 与手机 390px 两套视口截取 13 个页面，逐像素对比基线；超出 0.2% 失败并输出差异图，把此前手工截图检查固化成可重复流程。
- **测试**：`verify` 增加 manifest/Service Worker/图标/CSP 与缓存版本一致性检查；`smoke` 增加时长锁、睡前设置清洗、PIN 设置与锁定、趋势/有效性/建议、周报结构、故事探索度、冷静角不换页等 20 余条断言。
- **版本策略**：`GitVersion.yml` 打开 commit-message-incrementing，功能批次提交带 `+semver: minor` 时按语义化版本升级，普通修复仍自动递增补丁号。

## [1.0.6] - 封板前深度测试修复

- **签到（严重）**：修复签到满 400 条（或心情花满 365 朵）后再签到时抛 `ReferenceError`、点「种下这朵花」毫无反应的问题。根因是 `addCheckin` 的存档回调没有接收第二个参数（save），溢出归档分支取不到 `archive`。
- **统计**：家长面板的「心情签到」总数与「记下过的心情」次数现在包含已归档的更早记录（此前第 401 条起会突然缩水），表头明确标注「含归档」。
- **雷达图**：零练习时不再画出一个小五边形（会被误读为"已经练过"），改为空网格 + 中心点 + 文字说明；有数据时标注最外圈对应的次数。
- **存档安全**：导入备份的档案 id 收紧为安全字符（拒绝 `__proto__` / `constructor` 等），统计与索引对象改为无原型对象，避免构造的备份污染对象原型。
- **交互**：呼吸练习完成后锁住「开始 / 先停一下」，避免误点清掉「收下星星」；关卡完成按钮结算后置灰并显示「已收下星星 ✓」，完成弹窗被误关后不会出现"点了没反应"。
- **朗读**：缓存中文语音（`voiceschanged` 后刷新），普通话优先、本地语音优先，避免第一句用英文声音念中文；关闭朗读时立即停止当前语句。
- **无障碍**：换页后把焦点交给新的主内容区；弹窗补 `aria-label`；`prefers-reduced-motion` 下不再让无限动画在后台空转。
- **健壮性**：本地预览服务拒绝含空字节的路径（此前可让进程抛异常）；故事数据缺失时只给返回入口，不再用「回到地图」按钮误发星星；昵称/备注按字符截断，不再切坏 emoji；导入文件读取失败会给出提示。
- **桌面安全**：显式开启渲染进程沙箱、关闭拼写检查（避免在线词典下载）、统一拒绝摄像头/麦克风等权限申请、禁止 `<webview>` 挂载，导航限制在应用自身目录。
- **测试**：新增溢出归档、原型污染、HTML 转义、未知路由、焦点管理、雷达零状态、完成按钮锁等回归用例；静态校验新增主键唯一性、Electron 安全基线与样式表结构检查。

## [1.0.5] - 收尾：计时器、故事结算与记录展示

- **资源**：彩带与「冷静工具箱」练习计时的定时器改为统一登记，弹窗关闭或换页时立即清掉。此前关掉练习弹窗后计时器最多还会空转 1 秒，换页后残留的彩带也会继续飘 1.4 秒。
- **故事关**：选项的能力点改为点「继续故事」时才写入，只点开看看又离开不再计数；同时只在第一次走完该关卡时累加，重玩可以继续探索别的分支，但不会把同一份练习反复记成新的能力点。
- **签到**：第 4 步新增可选的「给自己留一句话」输入（最多 120 字），写下的内容会跟着这一次签到一起保存。
- **记录展示**：心情花园的花朵详情现在会显示当天写下的那句话和试过的小方法；档案页显示每个档案「加入日期 / 最近一次玩」；家长面板新增「最近的签到」表（日期、心情、强度、写下的话）与最近一次记录时间。
- **存档**：超出展示上限的签到（400 条）与心情花（365 朵）不再直接丢弃，而是自动移入归档（每档最多 2000 条签到 / 1000 朵花），随导出备份一起保存、导入时一并还原；「清空当前档案进度」会连归档一起清掉，删档也不会留下孤儿数据。
- **测试**：新增计时器清理、故事技能点结算时机、签到备注写入与展示、归档往返与清空等回归用例。

## [1.0.4] - 发布后复查修复

- **安全**：本地预览服务 `desktop/serve.mjs` 原先监听 `0.0.0.0`，局域网内其他设备可读取整个项目目录；现改为只绑定 `127.0.0.1`。
- **存档**：坏档备份改用固定 key，并在备份成功后立即把可用新档写回主 KEY；此前每次启动都会新增一个 `-corrupt-<时间戳>` 备份且永不清理，localStorage 只增不减。
- **存档**：用户/备份可控的字符串字段统一限长（昵称 12、原因/备注 500、其他短字段 40–60 字），拒绝超过 5 MB 的备份文件，避免把 localStorage 配额撑爆后静默降级。
- **存档**：心情花保留上限由 120 提高到 365（约一年），花园在达到上限时明确提示「最近 N 朵、更早的会自动收起来、可导出备份」，不再把截断后的数量写成「一共」。
- **无障碍**：弹窗打开时把键盘焦点移入弹窗，Tab 在弹窗内循环，关闭后把焦点还给原元素；此前焦点一直留在背景页面。
- **文案**：删除「连续签到还有小惊喜」（并无对应奖励逻辑）；练习弹窗改为「完整做完一次才会记下练习次数」，与实际计次行为一致。
- **一致性**：首页快捷卡与地图标题的小岛数、玩法说明页以外的「5 个小方法」改为从课程数据实时读取。
- **打包**：`build.files` 排除仅供开发用的 `desktop/serve.mjs`，便携版不再附带本地服务器。
- **文档**：修正 README 中五座小岛的名称、签到四步流程、贴纸与家长面板功能描述，补齐 `scripts/release-notes.cjs`，修掉两处笔误。
- **测试**：`verify.mjs` 增加「每关只拿最低星数」的解锁可达性模拟与预览服务绑定地址检查；`smoke.mjs` 增加坏档备份、超长字段截断、弹窗焦点、花园上限文案、数量动态一致等回归用例。
