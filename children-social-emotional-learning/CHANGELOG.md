# 更新日志

本文件记录心晴岛（Sunny Isles）的版本变更。版本号遵循语义化版本（SemVer），并与 git tag `children-social-emotional-learning-vX.Y.Z` 对应。

## [1.3.1] - 封板复审：异步语音、点读可达性与统计口径修复

> 不改玩法，只把 v1.3.0 在真实浏览器和畸形数据下会出问题的地方钉牢。两轮独立只读审查 + 故障注入测试后的定稿。

### 🐛 修复

- **朗读 watchdog 提前跳句（严重）**：超时原来固定按 300ms/字估算，慢速（家长 0.7× 语速 × 咕咕老师 0.86 倍率）下会在句子还没念完时提前 `done()`，下一句被塞进浏览器内部队列，声音与高亮脱节。现按实际语速估算（上限 120s），且 `speechSynthesis.speaking/pending` 为真时自动续期。
- **cancel→speak 被吞（严重）**：Chrome/Electron 偶发吞掉新 utterance 且不回调，旧逻辑的 watchdog 会把整段题当成「已念完」静默跳过。现先重试一次，仍无回调才兜底复位。
- **禁用按钮点读失效（严重）**：真实浏览器 disabled 控件（含子元素）不派发 click，选完做法后选项全部禁用，点读模式在最需要复听时反而哑掉。现开启点读模式时临时解除禁用（捕获拦截保证不会误选），退出后恢复。
- **高亮漏命中**：朗读稿前缀「做法 1：/答案：/篮子：」与带 emoji 的元素文本互不为子串，配对/分类/说一说多处不高亮。现按码点剥离装饰、去掉朗读前缀后做精确匹配，并对短公共子串降权，避免反过来误高亮小标签。
- **角色污染**：故事 panel 的 `data-role` 被「做法」继承，导致自动连读用团团、手动点读却用小火苗。现 role 只挂在正文区与反馈框；故事反馈框补上逐句点读标注。
- **弹窗 / 时间锁**：出现时统一停止朗读、清除高亮、退出点读模式，不再出现「锁屏背后还在念」。
- **键盘可达**：非交互可点读文本补 `tabindex/role/aria-label`，支持 Enter / Space 逐句朗读。
- **unsupported 文案**：浏览器不支持朗读时不再把家长导向「看怎么添加」的无解页面，设置页改给换浏览器建议。
- **统计口径**：`expressionStats().week` 加「本周一~周日」与「不超过今天」上界，导入时丢弃未来日期；家长面板每日上限文案与 `dailyCap()` 同源；`weekStrip()` 改用清洗后的 `byDay`；注明「最常练的句式」只统计独立练习页。
- **静默失败**：课程数据单点畸形不再吞掉整份话题白名单；`recordExpression` 返回 null 时恢复「我说出来啦」按钮，不再永久锁死。
- **资源与确定性**：`markReadable` 不再 `cloneNode` 整棵子树；复用已有 `data-say` id 防止同页重绘累积孤儿；独立页首卡只渲染一次；视觉基线固定 `Math.random` 并等待 `document.fonts.ready`。
- **文档如实说明**：README 把「无网络请求」改为「无外部/跨域请求；PWA 导航时仅向同源回源取最新页面」。

## [1.3.0] - 逐句点读、角色化语音与两种示范

> 继续把「听」和「说」做细：孩子能一句一句点着听、看着高亮跟读；三位伙伴各有自己的声音；同一件事既能练「对同伴说」，也能练「对大人说」。全部仍在本机完成，不录音、不联网、不保存孩子说过的话。旧存档自动补上新字段。

### ✨ 逐句点读 + 正在读的文字高亮

- **点哪句念哪句**：题干、玩法说明、故事正文、结局的道理、反馈、说一说卡上的场景与示范句，都能直接点一下朗读；朗读时那一句会**高亮成暖黄色**，念完或被打断自动清除高亮。自动读题连读时，高亮也会跟着一句一句走。
- **点读模式**：播报条新增「👆 点读模式」。打开后连**选项、配对卡、分类卡**也变成只读不选，孩子可以把所有做法先听一遍再决定；再点一次回到正常玩法。实现上用捕获阶段拦截点击，不与任何题型的原有交互抢事件。
- 换页自动退出点读模式并清除高亮；`Alt + R` 重听、手动小喇叭、自动读题三条路径共用同一套高亮状态。

### ✨ 角色化语音

- **团团 ☁️（音高 1.18 / 语速 ×0.95）、咕咕老师 🦉（0.92 / ×0.86）、小火苗 🔥（1.32 / ×1.08）** 用同一套本机中文语音、不同音高与语速区分，不加载任何音频文件。
- 互动故事按每段的 `speaker` 自动切换声音，结尾的「这个小故事的道理」交给咕咕老师；引导气泡的小喇叭也跟着角色走。朗读队列支持**逐句带 role**，一段故事里三个人可以各说各的。
- 家长可在设置里关掉「角色化语音」，三种声音就统一回同一个；与已有语速设置相乘生效（自动夹在 0.5–1.5 之间）。设置页可分别试听三位伙伴。

### ✨ 没有中文语音时，给家长一句能照着做的话

- 新增语音可用性检测：明确检测到「有中文语音 / 没有中文语音 / 浏览器不支持」三态；`getVoices()` 一直为空只算「未知」，**不误报**（有些环境不列声音但仍能念中文）。
- 设置页新增「🔊 这台电脑的中文语音」卡：状态说明、Windows / macOS 添加中文语音包的具体步骤、「试听一句」按钮，以及三位角色的分别试听；`voiceschanged` 到达后自动刷新。
- 关卡播报条下方只在明确缺语音时出现一行小字给家长，附「看怎么添加 →」，不打扰孩子。

### ✨ 同一话题，两种示范

- 12 张情境卡 + 19 关话题，每条都补了 **`demoAdult`**：对同伴说更短更直接；对大人说带称呼、把需要什么帮助讲清楚。说一说卡上「👫 对同伴说 / 🧑 对大人说」一键切换，切换即朗读新的示范，逐句点读的文本也同步更新。
- 点「我说出来啦」时会记下这次练的是哪一种（只存 `peer` / `adult` 两个计数，不存内容）；家长面板显示「对同伴说 N 次 · 对大人说 M 次」，方便陪孩子把两种说法都练到。

## [1.2.0] - 全关卡朗读 + 说一说（勇气小话筒）

> 让每一道题「会说话」，再给孩子一个把心里的话大声说出来的理由。新增功能全部离线完成，**不申请麦克风、不录音、不做语音识别、不联网、不保存孩子说过的任何一句话**；旧存档自动补上新字段，无需迁移。

### ✨ 全关卡文字朗读（Voice Read-Aloud）

- **19 关 × 7 种题型全覆盖**：进入关卡自动连读「关卡标题 → 团团的引导语 → 题干 / 玩法说明 → 每一个选项或卡片 → 按钮在做什么」。此前只有部分反馈文字会朗读，题干、选项、连一连的卡面、分类篮、故事选项基本是「静音」的。
- **排序题不泄答案**：课程数据里 `items` 往往就是正确顺序，朗读稿特意打乱后再念卡片，避免一开口就把答案报出来。
- **反馈也要读出来**：选了某个做法 / 配对成功与没配上 / 拖动卡片 / 排错第几步 / 呼吸每一轮的开始与完成 / 故事每段正文、每个做法、结局的道理与探索度 / 分类完成时的解释与「今天学到」，全部有语音。
- **互动故事整段连读**：一个节点一次念完「说话人 + 正文 + 全部做法」；结局连「正文 + 道理 + 已发现几个结局」一起念，不再被下一句顶掉。「再听一遍」自动指向当前故事节点。
- **结算弹窗也读**：奖励、今天学到、新贴纸、给大人的话一次连读完；按钮本身不再抢读半句。
- **播报条**：关卡顶部常驻「🔊 团团把题目和选项都念给你听」，提供「🔁 再听一遍」「📖 听选项」「⏸ 停一停」，并显示正在读的那一句。手动重听不受「自动读题」开关影响，键盘可用 `Alt + R` 重听。
- **朗读队列与代次**：新增排队连读（`speakSequence`）与作废代次；换页、点新选项、关开关时旧的排队语音立即作废，不会在另一个页面继续念上一关的文字。语音服务失败或系统没装中文语音时静默降级，不卡住界面。
- **家长可控**：设置页新增「自动读题」独立开关（关掉后读题、反馈、鼓励、结算全部安静，但手动小喇叭仍可用）与「朗读语速」0.7×–1.2×（选完立刻试听一句）；右上角原有的「朗读文字」升级为总开关。两项偏好跨「清空进度」保留，随备份导出导入。

### ✨ 说一说 · 勇气小话筒（鼓励口头表达）

- **听示范 → 自己开口 → 自己确认**：每一关最后都有一张贴合本关情境的「说一说」卡（19 关各一条），先点「听团团说一遍」由中文语音念出三句式示范，孩子跟着大声说，再点「我说出来啦」。不判断说得对不对、不打分、不录音。
- **三句式脚手架**：「我觉得…（感觉）／因为…（事情）／我希望…（小请求）」，每句配提示与例句；独立练习页可一键听一遍三句话。
- **12 张生活情境卡**：彩笔被拿走、分组没被叫上、明天要上台、想让爸爸陪拼图……可「换一张情境卡」，也能选「说给谁听」（团团 / 自己 / 毛绒玩具 / 家人 / 朋友 / 老师），把练习迁移到真实对话。
- **看得见的勇气**：累计次数、连续天数、今日次数、最近 7 天小格；每天最多 3 颗勇气星（超出仍累计次数，避免刷分）；累计 1 / 5 / 15 次解锁 3 枚表达贴纸；8 句随机鼓励语（自动避开上一句）并用语音念出来。
- **独立页面 `#/express`**：首页新增「说一说」快捷入口，玩法说明页有专门一章，可随时来练一句。
- **家长能看到什么**：成长记录新增「开口表达」卡（累计 / 本周 / 连续天数 / 勇气贴纸 / 最近 7 天 / 最常练的句式），成长周报在有记录时补一行「这周把心里的话大声说出了 N 次」。界面明确写明只记录次数、日期与句式，不作为奖惩依据。
- **隐私边界**：不调用 `getUserMedia`、不使用 `SpeechRecognition`（联网服务）、不写任何语音或文本到 `localStorage`；CSP 继续保持 `media-src 'none'`，Electron 继续统一拒绝摄像头/麦克风权限申请。表达记录只含次数与日期，导入时按白名单清洗、防原型污染，「清空进度」会一并清掉。

### 🔍 封板终审（独立代码审查 + 深度回归）

- **修复（中）·播报条状态残留**：反馈朗读打断读题后，旧的「正在读…」和呼吸动画会永久挂着——`stopSpeak()` 现在会通知被打断的那一段复位状态。
