# 需求文档 — Web to Markdown

版本：0.1.0 ｜ 日期：2026-11-03 ｜ 状态：已实现

## 1. 背景与目标

日常阅读网页文章、文档、博客时，用户希望将内容快速保存为 Markdown 格式，归档到本地笔记系统（Obsidian、Typora 等）。现有方案（手动复制排版混乱、在线转换工具泄露隐私）体验不佳。

**目标**：提供一个完全离线、一键操作的 Edge 浏览器扩展，将网页内容高质量转换为 Markdown。

## 2. 用户故事

- 作为读者，我希望点击一下就把整篇文章转成 Markdown，以便粘贴到笔记软件。
- 作为读者，我希望只转换我选中的片段，以便摘录部分内容。
- 作为读者，我希望转换结果可以下载为 .md 文件，以便本地归档。
- 作为隐私敏感用户，我希望所有处理在本地完成，不上传任何数据。

## 3. 功能需求

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-1 | 智能正文提取转换 | P0 | 基于 Readability 算法提取正文，过滤导航/广告/页脚 |
| FR-2 | 选区内容转换 | P0 | 转换用户鼠标选中的页面内容 |
| FR-3 | 弹窗预览 | P0 | 弹窗文本框展示 Markdown，支持编辑与手动选择复制 |
| FR-4 | 复制到剪贴板 | P0 | 一键复制全部转换结果 |
| FR-5 | 下载 .md 文件 | P0 | 以页面标题命名，用户可选择保存位置 |
| FR-6 | 右键菜单入口 | P1 | 页面右键「转换整个网页」、选中文字右键「转换选中内容」（直接复制并在页面 Toast 提示） |
| FR-7 | 快捷键 | P1 | Alt+M 转换选区并复制 |
| FR-8 | GFM 支持 | P0 | 表格、删除线、任务列表、围栏代码块 |
| FR-9 | 链接处理 | P0 | 相对链接转绝对链接；图片保留原始 URL；剔除 base64 内联图片 |
| FR-10 | 元信息头 | P1 | 输出顶部附加标题、来源 URL、抓取时间 |
| FR-11 | 显式错误提示 | P0 | 所有失败场景给出明确中文提示，不静默失败 |

## 4. 非功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-1 | 完全离线 | 所有依赖本地打包，零网络请求 |
| NFR-2 | 隐私安全 | 不收集、不上传任何页面数据与用户行为 |
| NFR-3 | 最小权限 | 仅申请 activeTab、scripting、contextMenus、downloads、notifications，不申请 broad host permissions |
| NFR-4 | 性能 | 常规文章页转换 < 1s |
| NFR-5 | 兼容性 | Edge（Chromium）为主，兼容 Chrome 120+ |
| NFR-6 | Manifest V3 | 符合最新扩展平台规范 |

## 5. 边界与异常场景

| 场景 | 预期行为 |
|---|---|
| 正文提取失败（非文章型页面） | 提示「未能提取到正文，请改用选中内容转换」 |
| 无选中内容时触发选区转换 | 提示「没有选中内容，请先在页面上选中文字」 |
| 浏览器内置页面（edge:// 等） | 弹窗提示不支持；右键菜单场景通过系统通知提示 |
| 超大 base64 图片 | 自动剔除，避免 Markdown 被污染 |
| 剪贴板 API 不可用 | 回退 execCommand('copy') |

## 6. 成功标准

1. 常规文章页（如博客、新闻）一键转换，正文结构（标题/列表/代码块/表格）保留完整
2. 任意页面选区可转换并复制
3. 全程无网络请求（开发者工具 Network 面板验证）
4. 所有异常场景有明确提示
