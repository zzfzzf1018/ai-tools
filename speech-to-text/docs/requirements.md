# 需求文档

版本：1.1，日期：2026-10-31。目标：本地中文/英文媒体转写与时间轴字幕，Windows 优先。

## 功能需求

| 编号 | 要求 | 验收方式 |
| --- | --- | --- |
| FR-01 | 读取 MP3、MP4、MKV，兼容常见额外媒体格式 | 真容器解码及真实双语集成测试 |
| FR-02 | 中文、英文、自动识别，原语言转写而非翻译 | 引擎参数测试与双语真实关键词检查 |
| FR-03 | 每文件输出 UTF-8 TXT、SRT、VTT | 导出单测、CLI 测试、真实输出检查 |
| FR-04 | 字幕对应原媒体时间线，含延迟音轨与静音 | 人工时间边界单测和 3 秒延迟视频验收 |
| FR-05 | 桌面文件队列、参数、进度、预览、输出目录、取消 | Tk 布局及工作流自动化测试 |
| FR-06 | 命令行批量处理，错误可定位，失败不阻塞后续文件 | CLI 批量容错测试 |
| FR-07 | 首次模型下载与缓存，显式离线模式 | 真模型加载与离线集成验收 |
| FR-08 | 默认保护已有输出、允许显式覆盖 | 碰撞、覆盖及失败清理测试 |
| FR-09 | 无音轨、损坏媒体、参数错误提供错误结果 | 媒体、参数及入口单测 |
| FR-10 | 指定多音轨媒体中的音轨，0 为第一条 | 解码音轨选择测试 |
| FR-11 | 独立长文件选项默认关闭；GUI 勾选或 CLI --long-files 才走新路径 | 旧路径隔离、参数传递和 GUI 状态测试 |
| FR-12 | 新模式固定窗口解码、无两小时上限，保留原媒体时间轴与块边界词归属 | 样本一致性、超两小时稀疏真实媒体和内存上限测试 |
| FR-13 | 完成块原子检查点；取消或进程退出后同任务自动恢复，跳过已完成块识别 | 取消、进程崩溃、真实双语恢复一致性测试 |
| FR-14 | 校验媒体和配置；拒绝损坏检查点及同任务并发；发布中断可恢复，保护外部改动 | SHA-256、配置变化、原子写入、文件锁、发布故障注入测试 |

## 工程需求

| 编号 | 要求 |
| --- | --- |
| ER-01 | README、Git 忽略规则、需求、设计、测试与审查记录 |
| ER-02 | 双击一键测试与打包，中文阶段提示，日志可定位，失败中止，Windows 便携目录、ZIP 与 SHA-256；普通使用者无需 Python |
| ER-03 | 锁定已验收依赖；隔离构建环境；CI 检查及产物上传 |
| ER-04 | 模型与媒体不入库；不上传用户音视频；不将管理员权限作为默认条件 |
| ER-05 | 开发、审查、修复、回归闭环；不以模拟识别测试替代真实模型验证 |
| ER-06 | 普通用户可双击帮助入口打开离线图文手册；清楚区分源码、应用包、模型；明确首次准备、转写、分享与故障处理 |

## 非功能需求

- NF-01：桌面转写在后台线程中执行，Tk 操作只在主线程。
- NF-02：CPU/int8 为基线，Python 3.13 x64 是构建验收环境。
- NF-03：默认整段模式仍限 2 小时；可选长文件模式 PCM 窗口最多 304 秒，字幕与模型内存另计；按文件串行处理，复用模型。
- NF-04：字幕片段非负、非空、有限时间、单调且不重叠，保留原媒体时钟。
- NF-05：输出目录可写，默认不覆盖；导出异常避免新文件半成品残留。
- NF-06：静音不虚构文字的自动门禁限全零数字静音；一般 ASR 准确率不能保证 100%。
- NF-07：恢复重新哈希和顺序解码，不要求容器精确 seek；每五分钟核心块提交，最多重跑一个未提交块。系统断电、存储损坏和多进程覆盖同名输出不在保证范围。

## 范围与封板

本版本不要求麦克风实时输入、云服务、说话人分离、翻译、强制逐词高精度对齐或字幕手工编辑。
字幕定位由 Whisper 提供，文件时间格式精确到毫秒，但定位误差需用业务录音抽检。
GPU 可配置但不作为 CPU 发行版封板条件。

工程封板条件：标准测试、静态检查、依赖一致性、真实双语格式验收、延迟音轨验收、打包后原生诊断及实际转写通过，未解决 P0/P1 缺陷为零。
业务封板条件：另需用户代表性音视频的准确率、时间偏差与性能确认，不能由合成语音替代。
