# 审查与发布记录

当前候选版本：1.1.0，日期：2026-10-31。以下保留 1.0.1 历史发布记录。

## 1.1.0 长文件审查

- 默认关闭 GUI 复选框和 CLI `--long-files`；默认解码、两小时上限、模型参数和原导出器未替换。
- 独立固定窗口解码、两秒重叠词归属、原时间轴映射；保留延迟音轨、数字静音及多格式支持。
- 完成块原子检查点、媒体完整 SHA-256 和识别设置校验、系统文件锁；取消/子进程退出后复用完成块。
- 审查发现最终导出中断会阻挡恢复，已增加持久发布计划与哈希归属校验，补测覆盖/不覆盖中断和用户修改输出。
- 实测发现 Windows 只读句柄 fsync 失败，已修复为可写句柄并回归；静态导入/行长问题已修复。
- 已运行完整标准回归和真实 small 双路径验收，包括超过两小时时间轴、解码内存和中英块边界恢复一致性。
- 最终工程封板以当前出包的 JUnit、源码冻结指纹、十一例 EXE 报告、ZIP CRC 和 SHA-256 为准；任一门禁失败不得分发。
- 新版不继承旧版人工批准，不自动提交、推送或打标签。持续长会议的业务准确率、独立干净机器和 GPU 仍需用户验收。
- 恢复会重新哈希和顺序解码；固定的是 PCM 工作集，不是模型或全部字幕内存。最长重跑一个未提交五分钟块。
- 系统断电和存储损坏不保证恢复；多人同时覆盖同名输出不支持。块边界识别可能有误差，真实业务字幕需校对。

操作见 [外部验收](external-acceptance.md)。本机没有可用 Windows Sandbox/Hyper-V 命令，未修改系统权限或启用虚拟化来制造干净机器通过。
真实测试视频、转写文件和抽帧保存在代码库外，不随本次提交或标签入库。

## 已知边界

模型首次下载需要网络，便携包不捆绑模型；大模型需要更高资源。
取消不能打断当前原生推理；默认模式媒体最长 2 小时，1.1.0 可选长文件模式例外；不支持实时输入、说话人分离、翻译或编辑。
`pkg_resources` 弃用警告来自固定推理依赖，后续升级必须重复真模型与便携包验收。
跨文件的断电原子性不保证，不处理恶意输入的安全隔离；只对可信媒体做本地转写。
