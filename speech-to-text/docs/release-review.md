## 封板状态

工程封板通过：未发现未解决的 P0/P1 缺陷。
本地结果：38 项标准测试通过（无跳过）；10 项真实 small 模型集成测试通过；
5 项便携 EXE 验收通过（英文 MP3、中文 MP4/MKV、延迟音轨、全零静音）。
Ruff、格式、pip check、源码和便携包原生诊断均通过，Windows EXE 已生成。
工程发布范围为 Windows x64 + Python 3.13 构建 + CPU/int8 + small 多语言模型。
合成媒体通过不代表真实业务准确率已经验收；GPU、其他系统与业务样本仍需独立验证。

## 已知边界

模型首次下载需要网络，便携包不捆绑模型；大模型需要更高资源。
取消不能打断当前原生推理；媒体最长 2 小时；不支持实时输入、说话人分离、翻译或编辑。
`pkg_resources` 弃用警告来自固定推理依赖，后续升级必须重复真模型与便携包验收。
跨文件的断电原子性不保证，不处理恶意输入的安全隔离；只对可信媒体做本地转写。
