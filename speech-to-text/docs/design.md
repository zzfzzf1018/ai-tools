# 设计文档

## 架构

```text
GUI (Tk / main thread) -- queue -- Worker (sequential batch)
CLI (argparse) ------------------ Transcriber / Options
                                      |
                      PyAV decode / resample / PTS reconstruction
                                      |
                         float32 mono PCM / 16000 Hz
                                      |
                   faster-whisper / CTranslate2 / CPU int8
                                      |
                         normalize / validate Segment
                                      |
                    stage UTF-8 TXT + SRT + VTT / publish
```

模块：`media.py` 决定媒体解码与时间线；`engine.py` 决定模型配置、缓存、取消和流程；
`subtitles.py` 决定验证、格式与持久化；`cli.py` 和 `gui.py` 仅负责用户入口。
不自行实现语音识别、容器解析、编解码或语言检测。

## 时间线

媒体起点为 `container.start_time / av.time_base`，未知时采用 0。
每个重采样音频帧的目标 PCM 索引为 `round((frame.time - origin) * 16000)`。
缺失时间戳时延续上一个样本索引，负时间部分裁切，正间隙填零。
视频起点为 0、音轨从第 3 秒开始时，PCM 前 3 秒为静音，不把字幕整体提前。
支持的容器和编码由 PyAV 自带库决定，不调用外部 shell 或系统 FFmpeg。

Whisper 在完整重建 PCM 上返回片段时间，设置 `task=transcribe`、`word_timestamps=True`。
输出保留片段边界，而非宣称逐词字幕；按源音频时间约束范围并消除模型片段重叠。
导出统一四舍五入到整数毫秒，再格式化，防止秒/分进位错误；极短片段保证至少 1 ms 可见。
纯数字静音直接跳过模型，避免 ASR 对静音幻觉。一般静音噪音不应用激进能量阈值，避免删除轻声讲话。

## 状态与并发

单文件：等待 → 解码 → 模型加载 → 片段推理 → 导出 → 完成/无语音。
异常进入失败；取消在安全边界检查，当前原生调用返回后响应。
批处理串行复用一个模型。GUI 只从队列消费进度、结果、失败和完成事件，工作线程不访问 Tk。
启动时冻结文件和参数快照并禁用编辑，避免用户变更与执行状态竞争。
关闭时请求取消；已完成文件保留，未完成文件不导出。

## 文件与故障

字幕数据先完整验证，再暂存三个 UTF-8 文件。默认模式预检已有目标并以排他创建处理竞态。
任何新文件写入失败会清理本次创建文件。覆盖模式先备份旧输出，再每文件原子替换；普通写入异常恢复旧集合。
同时限制最终 PCM 时长与累计解码样本量，避免重复时间戳使解码片段无限累计。
跨三个文件不是系统级原子事务，断电和进程被强杀不提供恢复保证。
不自动删除输入；模型下载到缓存，不将用户媒体复制到模型缓存。
损坏/无音轨/超时长媒体拒绝；不创建 web 服务、不开放监听端口。

## 技术选择与依赖

- Tk：Windows 原生桌面，不增加浏览器服务或前端框架。
- PyAV 16.1：内置容器与解码依赖，避免用户手动配置 FFmpeg PATH。
- faster-whisper 1.2.1：中文/英文多语言 Whisper，自动语言识别及时间戳。
- CTranslate2 4.6.0：真实模型验证通过的 CPU 核心版本，依赖 setuptools 80.9.0 的 `pkg_resources`。
- 不使用 ONNX VAD：本机原生加载验证失败；核心转写使用 Whisper 自带无语音判断，不依赖此路径。
- pytest + Ruff：功能回归、静态检查及格式门禁；PyInstaller 目录模式降低单文件解包成本。

构建环境仅支持 Python 3.13 x64 的锁文件。包元数据允许 3.11–3.13，但其余 Python/系统不属于本次已测试矩阵。
发行包包含解释器及原生库，不含模型、用户媒体、GPU 运行库；保留 console 以支持 CLI 和诊断。

## 演进边界

长文件需要分块或磁盘映射及时间戳映射再设计，不能直接去掉时长限制。
如增加 VAD，必须验证切除静音后时间回映射及 Windows 原生兼容性。
如增加强制词级对齐、多人标签或字幕编辑，需要新的需求与真实数据门禁。
