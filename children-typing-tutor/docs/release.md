## 后续审查与修复

- 弹窗焦点：限制 Tab/Shift+Tab，Escape 关闭并恢复焦点；已回归。
- 完成后导航：区分完成会话 ID，结果页离开不再误提示；已回归。
- 开发服务：生产 CSP 改为构建专用 HTML 钩子，开发启动和生产严格策略均有测试。
- 安全依赖：升级 Vitest 5.0.5，移除旧测试工作池严重漏洞；严重、高、中风险归零。
- 便携测试：NSIS 包装器不提供主进程调试管道，改为独立 CDP 连接；加入完成守卫，消除未决清理 Promise 静默退出。
- 封板复测：Windows 上包装器退出可能早于 Chromium 主进程，导致重启连接失败或临时目录文件锁；测试改为等待真实浏览器进程退出，便携包连续通过两次并回归目录包。
- 矮屏：1280×800 键盘底部原先超出首屏，仅收紧矮屏桌面间距，新增完整视口断言并通过。

## 低风险依赖处置

`deepmerge` 原型污染公告 GHSA-gcqx-w48m-w2h4，沿 `@rollup/plugin-node-resolve` → `workbox-build` → `vite-plugin-pwa` 传播为四个低风险告警。目前上游最新 `deepmerge` 4.3.1 仍在公告范围；自动修复建议会破坏性降级离线插件，未采用。

此链仅用于本地离线资源构建，不进入应用运行依赖；本项目使用固定可信构建配置、不合并用户提供对象。本次接受并披露低风险，后续跟踪上游补丁。运行依赖与 Electron 安全隔离检查通过，不将此结果表述为“所有依赖零漏洞”。
