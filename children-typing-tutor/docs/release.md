## 目录触发与升版发布规则调整（2026-10-31）

本节覆盖下节原来的标签触发规则：Actions 只监听 `children-typing-tutor/**` 的 main push 与 PR；移除根工作流路径、标签和手工触发。未修改本项目目录不触发；版本不变仅跑完整 pipeline；main push 中本项目 npm 正式版本严格升高、全部门禁通过后才发布。PR 中升版仍不发布。

版本比较读取整次 push 的 before 与当前 SHA 下本项目 npm 元数据，使用根相对路径，避免只看末次提交或读到其他项目版本；GitVersion 开发计数变化不视为发布升版。升版仅在临时 CI checkout 建本地标签用于 GitVersion 计算，正式发布任务在验收通过后于精确 push SHA 上创建远程标签与下载；拒绝降版、预发布和重复标签。

本轮应用单测 36 项、构建/发布回归 21 项及真实 Git/GitVersion 集成 2 项通过，涵盖版本未变、升版、PR、标签、降版、多提交 push、同仓其他项目版本隔离、开发计数变化及重复标签拒绝。ESLint、Prettier、编辑器诊断和官方 SHA-256 校验后的 actionlint 1.7.7 工作流检查均通过。课程、打字与打包实现未改动，沿用下节实际 exe 与浏览器验收证据，不冒充本轮重新执行；远程 Actions 尚未触发，未提交、推送或创建当前仓库标签。现行操作见[发布文档](publishing.md)。

- 每个可打印尝试按目标键汇总尝试数和正确数；大小写分别记录，退格不抹历史，输入过滤与原准确率规则不变。仅完成的小测、普通练习、专项与游戏保存，跟练及未完成会话不保存，不记录逐次输入历史。
